# cutflow-prompt — AI 生视频提示词

一句话:给画面构想/分镜/图片 → 产出**首帧图提示词** + **首帧标注式 5–10s 图生视频提示词**(可选尾帧)。方法论蓝本:make-prompt-seedance2(structured-prompt 四段公式 + 真人感九维度)。

## 输入

用户给的:画面构想文字 / 分镜表 / 参考图片(可先用 OCR/VQA 读图)。

## 输出(固定七段)

1. 路线理由(一句话:为什么这样写)
2. 图片理解摘要(有参考图时)
3. 理解确认(一句话复述,automation 模式仅记录不等待)
4. **完整提示词**(独立代码块,直接可复制)
5. 素材建议(@图片上传顺序与用途)
6. 使用提示
7. 迭代建议(5% 微调法:每次只改 1-2 个关键词)

## 首帧图提示词模板

```
写实摄影风格,<景别>,<主体外观:照实描述,不加主观美化>,<服装/材质细节>,
自然光主光源<位置>,浅景深 f/1.8,前景虚化,皮肤纹理可见,无美颜滤镜,
<氛围>氛围,16:9/9:16,高清细节
```
词库:真人感九维度(不完美即真人,保留 20% 不完美/给过程不给顶点/皮肤四层:纹理-血色-水油-光皮互动/运镜=起始景别+方式速度+落点/光源=位置+类型+强度/背景必须有动态元素)。

## i2v 提示词模板(5–10s)

```
【风格】<风格>,<5-10>秒,<比例>,<氛围>
【时间轴】0-X秒:以@图片1为首帧,<单一核心动作+镜头运动>;
          X-末秒:<第二拍,单镜头单动作,物理连贯>
【声音】<配乐风格> + <关键音效> + <对白(如有)>
【参考】@图片1 作为首帧,@图片2 作为角色形象参考(如有),@图片3 作为尾帧(如需要)
```

硬约束:
- **主体描述必须与首帧图照实一致**(颜色/材质/细节照图写,冲突会生成扭曲);
- 单镜头单动作;每拍一个核心动作;
- 音频指令必须显式写(不写=随机出声);
- 角色标注:画面角色的外观要点在【参考】后逐条列出(照首帧图写实);
- 尾帧用法:首帧=初始状态,尾帧=最终效果(生长/对比类);
- 知名 IP 形象写 "Figure 1/2" + 外观描述,不写名字;
- 负面提示词用自然语言在结尾一句。

## 废片排查

模糊→放慢运镜+加锐度约束;脸崩→简化描述+减少动作;产品变形→@图锁定+"1:1 还原产品"。
