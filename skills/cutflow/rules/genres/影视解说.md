# 影视混剪 / 解说类 · 剪辑手册

> 调研 2026-09-08。来源:【官方】YouTube Fair Use 帮助文档;【权威】斯坦福版权与合理使用中心;【经验】知乎解说实操/Recapo;【判例】图解电影案、谷阿莫诉讼(人民网)。

## 节奏参数表

| 参数 | 值 | 来源 |
|---|---|---|
| 解说语速 | ~200 字/分钟(悬疑解说案例) | 【经验】 |
| 解说:画面比 | 解说词覆盖约 7 成时长、原片画面 3 成(7:3);剧情还原:个人解读 = 6:4 | 【经验】 |
| 原声 vs 解说 | 关键对白保留原声推进叙事,其余由解说覆盖 | 【学术+经验】 |
| 钩子 | 前 3 秒,"反问 + 离奇事件"开头公式 | 【经验】Recapo |
| 常见体量 | "N 分钟看完"式 3–5 分钟(注意:该形态本身是侵权高发区) | — |

## 结构模板

`前 3 秒悬念钩子(反问/离奇事件)→ 三幕主线压缩(起因-冲突-高潮,解说与画面逐句对齐)→ 收尾观点/评价(避免纯流水账)`

## 剪辑手法

- 先拆解场景、标注镜头,再让文案语义与画面片段匹配(解说的核心技术问题);
- 剧情推进用快剪,情感段落放慢保留原表演;
- 解说词全程上字幕;引用原声对白保留原声且字幕区分(引号)。

## 版权红线(此类最重要差异)

【官方】YouTube 合理使用四要素:①使用目的与性质(转化性/评论批评优先);②原作品性质;③使用量与实质性;④对原作市场的影响。
- **没有任何用量自动安全**——引用短也可能侵权;
- 中国实践:"不论长短,用了就必须尊重著作权";"图解电影"案与谷阿莫诉讼是反面判例;
- 安全做法:增加原创观点/批评性内容、控制单部影片引用量、避免"3 分钟看完"纯剧透替代观影、警惕 Content ID。

## CutFlow 对应
- 影视素材由用户提供(本库不抓取正片);
- 解说配音走音色卡;原声段落 volume 保持,解说段 ducking 自动;
- 双字幕轨概念:解说字幕(常态)+ 原声对白字幕(引号区分),ASS 双 Style 实现。
