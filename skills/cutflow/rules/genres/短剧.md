# 短剧类(竖屏微短剧)· 剪辑手册

> 调研 2026-09-08。来源:【官方】广电总局微短剧分类分层审核(新华网发布)/火山引擎(字节);【数据】东方财富研报/流媒体网;【经验】爆款拆解(大众新闻/什么值得买)。

## 节奏参数表

| 参数 | 值 | 来源 |
|---|---|---|
| 单集时长 | 1–2 分钟/集 | 【数据】36氪 |
| 景别 | 近景+特写为主;对话用交替特写+反应镜头;动作戏用局部特写链 | 【经验】爆款拆解 |
| 切换频率 | 3 秒一个钩子、5 秒一个反转;禁废帧;前 7 秒完成情绪锚定(70% 用户前 3 秒划走) | 【经验】 |
| 付费卡点 | 主流第 9–10 集;断在高潮/悬念顶点("情绪未完、剧情刚断") | 【数据】研报 |
| 字幕 | 对白字幕置底部安全区;出海单行 ≤42 字符 ≤2 行 | 【官方】火山引擎 |

## 构图(竖屏特有)

- 中心聚焦/对角/井字,垂直三分法;人物上下入画的纵向轴线暗示权力关系;
- 用门框、台阶、走廊等纵向元素填满画面。

## 结构模板

单集:`前 3 秒冲突/悬念 → 新冲突+旧伏笔+情绪爆点(每集三件套)→ 最后 3–5s 强悬念/反转留坑`
整部:`黄金三集立人物与冲突 → 免费集养情绪 → 卡一(约第10集)高潮断点`。

## 音效音乐

- 情绪反应 0.2 秒内跟上重音音效;
- 剧情分段切换配乐;关键反转用强音效;结尾悬念音勾下一集。

## 合规红线【官方】
- 微短剧"分类分层审核"(按投资额+题材分重点/普通/其他三级);
- AI 生成内容有专项管理提示——AI 参与制作的短剧须按规定标识。

## CutFlow 对应
- 短剧素材通常是多机位多 Take:用 rs_asr 转写全部 Take → Agent 按"情绪节拍表"选 Take → IR 组装;
- 转场:硬切为主,情绪段落间 xfade;
- 音效轨:assets_sfx 重音类(pop/riser)按情绪点撒。
