# 口播 / 知识类短视频 · 剪辑手册

> 调研 2026-09-08。来源:【官方】YouTube 创作者频道/CapCut 创作指南/抖音创作者中心;【数据】Opus.pro 1350 万条短视频研究;【经验】Merra AI、迅课等。

## 节奏参数表(brief 缺省时采用)

| 参数 | 值 | 来源 |
|---|---|---|
| 视觉变化间隔 | 2–5s(跳切/推近/贴图/花字/音效都算) | 【经验+数据】"2-Second Rule";Opus.pro:变化多样性>频率 |
| B-roll/插图解 | 每 30–60s 一次,盖在跳切点上;头部视频仅 6% 用 B-roll、2.4% 用转场 | 【数据】Opus.pro |
| 语速 | 240–280 字/分钟(快节奏 300–330) | 【经验】 |
| 单条时长 | 科普 15–30s;结构完整 50–60s;深度知识 1–3 分钟 | 【数据】法治日报引抖音/Opus.pro |
| 字幕 | 单行 ≤15 字,底部安全区,白字描边,关键词变色 | 【官方】广电总局译制规范+平台惯例 |

## 结构模板

`钩子 0–3s(疑问/反差/结果前置,禁片头动画)→ 价值主体(要点×3–5,每 3–5s 一次视觉变化)→ 结尾 3–5s(下期钩子 + CTA)`
- CTA = "理由 + 动作",只主推一个动作,放在情绪最高点 1–2 秒;
- 前 30 秒留存 ≥70% 更易获推荐【数据】。

## 剪辑手法(CutFlow 对应)

- 跳切:剪掉停顿与口水词(rs_asr 时间轴 + IR 多 clip sourceIn 跳接);
- 视觉穿插:绿幕→虚拟背景(默认),知识/数据卡按语义节拍插入(ADR-0004);
- 字幕:talkshow-bold 或 tutorial-clean,textopt 轻改写;
- 音效:卡片切入 whoosh、要点 pop/ding(assets_sfx)。

## 红线
- 字幕无错别字、时间轴同步(抖音低质判定);无促销/导流字样(星图规范)。
