# 动画演绎教程类视频 · 剪辑手册

> 调研 2026-09-08。来源:【官方】Material Design 3 / Adobe 动画十二原则;【权威】NN/g 动效时长研究;【经验】Twine、Blue Carrot、TechSmith。

## 节奏参数表

| 参数 | 值 | 来源 |
|---|---|---|
| 场景切换 | 每 5–7s 一次场景/转场变化;钩子在前 3–5s | 【经验】Twine |
| 总时长 | 社媒 25–60s;标准 explainer 60–90s;深度 ≤2.5 分钟 | 【经验】Blue Carrot/Yans |
| 旁白语速 | 中文 ~240 字/分钟(对应英文 150wpm/90s 基准) | 【经验】Blue Carrot |
| 动效时长 | 文字/UI 动效 200–300ms,强调级 ≤500ms | 【官方】Material Design 3 |
| 缓动 | 入场 ease-out、退场 ease-in、屏内 ease-in-out、进度类 linear;禁线性匀速(机器人感) | 【官方】MD3+Adobe(迪士尼 Slow In/Out) |
| 文字出镜 | 1 秒/13 字符;最短停留 1.5s;≤2 行;一屏一个概念 | 【权威】legibility.info/SSW |

## 结构模板

`钩子/问题 3–5s → 问题放大 → 解决方案/步骤(每步一场景)→ CTA`
- **画面必须直接图解旁白正在说的内容**,不做纯装饰动画(TechSmith);
- 旁白承载主信息流,屏幕文字只放关键词;动效与旁白逐句对齐。

## CutFlow 对应(成片 B 纯动画模式)

- 场景 = artboard 卡(遵守 ADR-0009 安全区:内容垂直 15%–68%,底部 30% 留给字幕);
- 背景 = 6s 无缝循环动画(IR loop),保证无空白帧;
- 旁白 = 音色卡 TTS,句级时间轴驱动场景切换(rs_tts manifest);
- 动效:入场 fadeIn/slideIn 300ms(渲染器 motion 枚举),卡片内 GSAP 按 MD3 时长;
- 字幕 = talkshow-bold,与旁白同源(manifest)。

## 红线
- 文字停留 <1.5s 或 >40 字/屏 = 不可读;
- 全片同一场景超过 7s 无变化 = 掉留存。
