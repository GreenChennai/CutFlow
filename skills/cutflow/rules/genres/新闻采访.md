# 新闻采访类视频 · 剪辑手册

> 调研 2026-09-08。来源:【官方】NBCU Academy(媒体官方学院)/BBC Subtitle Guidelines/国家广电总局;【权威】DCMP/SPJ·ONA 伦理准则;【经验】Hollyland/Inside The Edit。

## 节奏参数表

| 参数 | 值 | 来源 |
|---|---|---|
| 剪辑哲学 | 不追求快切;按语义段落剪;同期声可收紧但**不得改变语义** | 【官方】NBCU Academy |
| B-roll | 剪成"序列"图解叙事;盖跳切点;B-roll 底部保留环境声(nat sound) | 【权威+经验】 |
| 常见时长 | 新闻包 1–3 分钟(按栏目惯例;经验值,无权威统一标准) | 经验值 |
| 字幕 | ≤2 行;底部字幕安全框内;中文 ≤15 字/行;说话人换人用 `>>` 或 `姓名:` | 【官方】BBC/广电总局/DCMP |
| 人名条 | 两行式 lower third:姓名(大)+职务/单位(小);首次出场出现 | 【官方】NBCU Academy Chyrons |

## 结构模板

`导语(记者出镜或旁白,非钩子)→ 同期声 1(受访者)→ B-roll 序列图解 → 同期声 2 → 记者收尾串场`
- 双人口:正反打/双人镜头交替,远程用分屏(two-box);
- 压缩回答产生的跳切一律用 B-roll 或反应镜头遮盖;
- 切回说话人宜在语义完整处。

## 严肃感红线(区别于所有其他类型)
1. **硬新闻不加背景音乐**——只留环境声与记者轨(公信力惯例);
2. 引语逐字为准;可轻度清理口头语,**严禁改写措辞、断章取义、用无关画面制造虚假暗示**(SPJ/ONA 伦理);
3. 转场用硬切或叠化,禁用花哨转场特效;
4. 字幕区分引语与旁白(引语可带引号)。

## CutFlow 对应
- brief 类型=新闻采访:强制 `bgm: 无`、转场枚举只用 fade、字幕 tutorial-clean + 说话人前缀;
- 人名条 = text 轨卡(两行,左下安全区)或 artboard 静卡;
- 响度照通用规则 -14 LUFS。
