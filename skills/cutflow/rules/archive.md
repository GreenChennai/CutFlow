# Archive — 工程文件归档与清理(ADR-0007)

## 目录命名

`<YYYYMMDD>-<中文标题>-<类型关键词>`,例:`20260908-店群运营拆分收入-口播绿幕`。
类型关键词 ∈ {口播绿幕, 口播, 纯文案, 动画教程, 新闻采访, 短剧, 影视解说}。

## 产物中文化命名(06_成片输出 顶层)

| 产物 | 命名 |
|---|---|
| 竖版成片 | 成片A_口播精修_竖版_最终.mp4(按 A/B/C 序号) |
| 横版成片 | 成片B_Jimi纯声音动画_横版_最终.mp4 |
| 封面 | 封面.png |
| 字幕 | 字幕_成片A.srt |
| 剪映草稿 | **半成品出口,不是交付物**(ADR-0052):落点 `05_时间线工程/导出/剪映59/`,不进归档交付面,更不进 `成品/` |

内部中间件(06_成片输出/_build、sub_*)保持 ASCII;字幕 sub_*/subtitles.ass 是重渲依赖,**保留不删**。

## 只读交付区(成品/,ADR-0052)

最终交付物由 `rs_ingest.py deliverables --publish` **拷贝**进 `成品/`(成片/字幕/封面/
文案/说明书/对账.md/半成品入口.md),工程区母版保留;`成品/` 整区只读语义,
rs_cleanup 永不清理它,半成品(工程文件/剪映草稿)混入即被只读区断言拒绝。

## 清理(rs_cleanup.py)

- 交付前必跑;先 dry-run 看清单,`--apply` 执行;
- 必删:_build、dev-*、*_probe*、*.log、*.tmp、试算目录、06_成片输出 顶层非中文命名文件;
- 必留:brief、文案、校对转写、中文产物、sub_*/、project.md、project*.json。

## 测试件铁律
临时试验文件一律 `dev-` 前缀或放 `99_试算/`;**完工即删**,不留过夜。

## Windows / Git Bash 引号与路径纪律(v0.12,安信德 #15)

- 路径以 `\` 结尾放进双引号会转义引号:`"...\fonts\"` → `unexpected EOF`;结尾反斜杠去掉或改 `/`;
- 中文路径 + 复杂引号的内联 `python -c "..."` 极易碎:**写成脚本文件再执行**;
- 详细对照表见 `references/ffmpeg-recipes.md` 的「Windows / Git Bash 引号与路径纪律」。
