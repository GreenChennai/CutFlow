# videoType = `drama` · 竖屏短剧

> M6 预登记册(ADR-0051 风格包落地首批新增;M8 手法库正式扩册)。来源分级:【官方】抖音创作者中心短剧内容规范;【经验】短剧从业者共识。风格包:`drama-vertical`(templates/styles/packs/drama-vertical/)。

## 1. 素材特征(与口播类的根本差异)

- **叙事在画面与台词里**,没有"口播稿";转写覆盖的是台词,粗剪对象是**废镜头与冗余铺垫**;
- **冲突密度决定完播**:前 3 秒必须给冲突/悬念,背景铺垫是划走的第一原因;
- 台词短促、情绪外放;配乐是情绪推手,对白段必须让频(ducking)。

## 2. 节奏策略

| 参数 | 缺省值 | 说明 |
|---|---|---|
| 节奏档 | `fast`(注册表) | 卡 900–3500ms、视觉节拍 2–3s,风格包 `params.yaml` 同源 |
| BGM | **开**,增益 -18dB,对白段 ducking | 【经验】鼓点/弦乐渐推铺情绪;台词优先 |
| 转场语法 | 硬切为主;时空转换 fade、爽点翻转 slide | 【经验】禁音乐踩点特技(snapToBeat=false) |
| 字幕 | `subtitle-white`,每卡 ≤14 字、CPS ≤9 | 【经验】台词比口播金句略长,14 字内保竖屏可读 |
| 单集时长 | 1–3 分钟 | 平台预设 durationHint 兜底 |

## 3. 字幕与卡片要点

- 字幕跟**台词**(wordline.json 为唯一真相源),情绪重音可用高亮词表;
- 卡片只做三件:集数/情绪标题卡、前情回顾、下集悬念预告(`cards.density=少`);
- 卡片视觉借 artboard `ecommerce-promo`(大字报强对比),与"爽感"同源;安全区同全库(底部 30% 留字幕带)。

## 4. 管线分支(本类型特有)

| 环节 | 做法 |
|---|---|
| S0 摄取 | 多机位/多集素材逐条 probe;集数命名建议带序号(`ep03_take2.mp4`) |
| S2 粗剪 | 以"废镜头/冗余铺垫"为主;`--auto` 下 review 刀全保留留痕 |
| S6 音频 | 对白段 ducking 必须生效;配乐渐推段不得压台词 |
| S10 文案 | 标题带悬念与集数钩子;不剧透反转 |

## 5. 该型验收清单(L1 目测 + 用户 L2 对照用)

- [ ] 前 3 秒有冲突/悬念(非背景铺垫、非黑场);
- [ ] 台词字幕无超红线(每卡 ≤14 字、CPS ≤9);
- [ ] 对白段听得清(ducking 生效),配乐情绪推得动;
- [ ] 片尾有下集悬念钩子,不剧透反转;
- [ ] 卡片不压字幕带、不挡表演主体(过 check_overflow --safe-area);
- [ ] 无音乐踩点特技转场;硬切无半帧闪烁。
