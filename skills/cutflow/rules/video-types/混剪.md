# videoType = `混剪` · 卡点/音乐驱动混剪

> 调研 2026-09-20(副文档 04 · 阶段四 N5 开放注册表首批新增)。来源分级:【官方】抖音创作者中心 / Bilibili 创作激励规范;【权威】版权四要素(YouTube Fair Use,见 `_通用规则.md` §版权);【经验】卡点混剪从业者共识。
> brief 已填的值优先;本册只在 brief 缺省时兜底。注册表条目:`mixcut-douyin`(templates/styles/registry.json)。

## 1. 素材特征

- **无旁白主线**:叙事由**音乐**承载,画面是素材碎片的节奏化排列;`wordline.json` 在本型常为空或仅歌词——**BGM 时间轴是骨架**,字幕/卡点以其为参照;
- **素材碎片极多且短**(0.5–3s/个),切换频率远高于其他型(视觉节拍 1–2s);
- 常含**影视/他人素材引用**:版权四要素是硬约束——转化性(有主题有观点)、控制单部引用量、不做"N 分钟看完"式纯剧透;AI 参与须标识;
- 高对比、高运动量的素材适合卡点;静态素材卡点效果差,选材阶段就该筛掉。

## 2. 节奏策略(注册表 `music` 档)

| 参数 | 缺省值 | 说明 |
|---|---|---|
| 卡时长目标 | **0.8–2.4s** | 踩鼓点/重拍;副歌段可加密到 0.5s(显式改,不留痕不算) |
| BGM | **开,时间轴骨架**,增益 -12dB(全库最高档) | ducking 只在保留人声对白处生效;无对白则 ducking 关 |
| 转场语法档 | 硬切为主 + 模板 `motion-info` 的 slide/circleopen 备选 | 转场**落在拍点上**;禁 0.3s 内连续双转场 |
| 视觉节拍 | 1–2s | 画面事件必须跟拍,自由发挥会散 |
| 语速 | 无旁白时 `wpm=[0,0]`(不适用) | 有解说轨时按 280–330(快节奏解说) |
| 单条时长 | 15–45s | 卡点型完播压力最大,宁短勿长 |

- **开头 1–2 个镜头必须踩在重拍上**并给最强素材(卡点型的"前 3 秒"被压缩到前 2 拍);
- 结构原型:`强钩子(2 拍)→ 铺垫段(主歌,渐密)→ 高潮段(副歌,最密)→ 定格收尾(1–2s)`。

## 3. 字幕与卡片要点

- 字幕:`subtitle-white`(模板 `motion-info`),只上**歌词钩子/点睛短句**(每句 ≤12 字、CPS ≤9 同全库红线);不逐句上歌词——卡点型字幕是**强调**不是**翻译**;
- 歌词字幕的进出场**对齐乐句边界**(不是字级起点),允许 ±1 帧内的吸附(帧量化纪律不变);
- 卡片:几乎不用信息卡;标题花字/角标用 artboard 单卡即可,安全区同全库;
- 结尾定格帧 + 订阅引导 1–2s,勿拖。

## 4. 管线分支(本类型特有)

| 环节 | 做法 |
|---|---|
| S0 摄取 | 素材碎片逐条 probe;**BGM 音频单独登记**(03_assets/bgm.mp3,授权源留痕) |
| S1 转写 | 无旁白可整段跳过(纯画面型);有解说轨走正常对齐;**BGM 不进转写** |
| S2 粗剪 | `dead_air`/`filler` 检测基本不适用(无连续语流);碎片取舍由 Agent 按拍点判断 |
| S3 组装 | 多 clip 微秒级拼接;卡点对齐由 Agent 按 BGM 波形定 `startMs`,脚本只做帧量化 |
| S6 音效 | 转场音效慎用(会打架 BGM);重拍处可用 impact 类 ≤2 个/15s |
| S7 字幕 | 歌词短句按乐句出手;CPS/字数红线不豁免 |
| S10 文案 | 标题带情绪词/名场面钩子;Tag 带原作名(标注引用,谨慎引流) |

## 5. 该型验收清单(L1 目测 + 用户 L2 对照用)

- [ ] 卡点成立:重拍处画面确有切换(抽查副歌 10 个拍点 ≥8 个对齐);
- [ ] BGM 增益/ducking 合理:无对白段音乐饱满,保留对白段人声听得清;
- [ ] 素材引用合规:转化性剪辑、单部引用量克制、无纯剧透替代;来源在交付说明留痕;
- [ ] 字幕只出现点睛短句,无逐句歌词刷屏;CPS/字数不超红线;
- [ ] 无连续花哨转场(0.3s 内双转场)、无半帧闪烁;
- [ ] 结尾定格 + 引导不拖沓;全片时长 ≤45s(超长需用户显式确认);
- [ ] AI 生成/参与素材已按规定标识。
