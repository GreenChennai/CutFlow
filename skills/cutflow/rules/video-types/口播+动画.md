# videoType = `talking-head+animation` · 口播 + 部分动画

> 调研 2026-09-08(源自原 `rules/genres/口播知识.md` + `动画教程.md`)。来源:【官方】Material Design 3 / Adobe 动画十二原则 / CapCut 创作指南;【权威】NN/g 动效时长研究、legibility.info;【数据】Opus.pro;【经验】Twine、Blue Carrot、TechSmith。
> brief 已填的值优先;本册只在 brief 缺省时兜底。

## 1. 与 `talking-head` 的全部要求相同，另加：

**人还是主体,动画是补充。** 绿幕抠像、虚拟背景、字幕规格、粗剪要求**原样继承**(见 `rules/video-types/纯口播.md` §1),额外承担"动画卡"的**流畅性**与**贴合性**。

## 2. 管线分支(本类型特有)

| 环节 | 做法 |
|---|---|
| 卡片生产 | artboard:HTML/CSS → PNG/MP4(≤15s,fps ∈ {10,20,25,50});`rs_artboard` 的 `manifest.json` 是唯一映射表(尺寸不符**报错不拉伸**) |
| 卡片插入 | 知识/数据/对比/章节四类卡(ADR-0004);插入点由 `wordline` 语义节拍决定,**每 2–3s 一次视觉变化** |
| 安全区 | 卡片内容垂直 **15%–68%**,底部 30% 留给字幕(ADR-0009);人物期与卡片期**不得压字幕带** |
| 转场 | 硬切为主;卡片进出用 `motion` 枚举(fadeIn/slideIn/scaleIn),时长 200–300ms |
| 声音 | 原声;卡片本身**不出声**,音效由 `rs_sfx` 落点(whoosh/pop/ding) |

## 3. 流畅性要求(硬线)

- **缓动**:入场 `ease-out`、退场 `ease-in`、屏内 `ease-in-out`、进度类 `linear`;**禁线性匀速**(机器人感)【官方 MD3+Adobe 的 Slow In/Out】;
- **时长**:文字/UI 动效 200–300ms,强调级 ≤500ms【官方 MD3】;
- **文字出镜**:1 秒/13 字符;最短停留 1.5s;≤2 行;一屏一个概念【权威 legibility.info/SSW】;
- **背景**:6s 无缝循环动画(`clip.loop`),保证无空白帧;
- 全片同一画面超过 **7s** 无变化 = 掉留存(同 `talking-head` 的 2–5s 视觉变化要求)。

## 4. 贴合性要求(硬线)

- **画面必须直接图解旁白正在说的那句话**,不做纯装饰动画【TechSmith:explainer 第一原则】;
- **卡片的时间窗必须落在它解说的那句话的时间窗内**(源:`wordline.json`);错位 >1 卡即视为不贴合;
- 屏幕文字只放**关键词**(旁白承载主信息流),卡片文案与台词同义不重复;
- 人物与卡片切换时,**口播不停**(动画盖在语音上,不是插播一段静音);
- 卡片不得遮挡人物面部;人物在画面时卡片走侧向/下半区,或短暂全屏但 ≤3s。

## 5. 结构模板

`钩子 0–3s(口播直给,禁片头动画)→ 价值主体(要点×3–5,每要点配 1 张卡)→ 结尾 3–5s(CTA)`

- 卡片数 ≈ 要点数;每张卡 ≤8s;卡片之间必有口播过渡,不连续叠卡;
- 前 30 秒留存 ≥70% 更易获推荐【数据】。

## 6. 红线

- 卡片尺寸不符 / 拉伸 = 直接报错止步(`rs_artboard`);
- 卡片压字幕带 / 压脸 = 不合格;
- 线性匀速动效、卡片与台词错位 >1 卡 = 不合格;
- 字幕规格与红线同 `talking-head`(无错别字、时间轴同步、无促销导流)。
