# videoType = `pure-animation` · 纯动画

> 调研 2026-09-08(源自原 `rules/genres/动画教程.md` + ADR-0006 成片 B)。来源:【官方】Material Design 3 / Adobe 动画十二原则;【权威】NN/g 动效时长研究、legibility.info;【经验】Twine、Blue Carrot、TechSmith。
> brief 已填的值优先;本册只在 brief 缺省时兜底。

## 1. 管线分支(本类型特有)

**没有真人画面,主信息流全部由旁白 + 场景卡承载。**

| 环节 | 做法 |
|---|---|
| **声音来源(二选一,必在 brief 声明)** | ① **音色卡 TTS**(`rs_tts`,默认 `koubo-test`);② **视频中人物的原声**:从口播素材抽音频轨当旁白(ffmpeg 抽轨 → 重采样 48k → 归一) |
| 时间轴 | TTS:逐句 wav **ffprobe 实测**时长 + 句内对齐;原声:素材自带时间轴。两条路都落到同一份 `wordline.json`。**TTS 无字级时间戳时标 `charTimingEstimated`,不假装字级**(见 `rules/align.md`) |
| 场景 | 场景 = artboard 卡(遵守 ADR-0009 安全区:内容垂直 15%–68%,底部 30% 留给字幕) |
| 背景 | 6s 无缝循环动画(`IR loop`),保证无空白帧 |
| 字幕 | `talkshow-bold`,与旁白同源;平台见 `rules/platforms.md` |
| 粗剪 | 有原声时**必做**(口误重录/中间段);纯 TTS 无粗剪需求 |

## 2. 节奏参数表

| 参数 | 值 | 来源 |
|---|---|---|
| 场景切换 | 每 5–7s 一次场景/转场变化;钩子在前 3–5s | 【经验】Twine |
| 总时长 | 社媒 25–60s;标准 explainer 60–90s;深度 ≤2.5 分钟 | 【经验】Blue Carrot/Yans |
| 旁白语速 | 中文 ~240 字/分钟(对应英文 150wpm/90s 基准) | 【经验】Blue Carrot |
| 动效时长 | 文字/UI 动效 200–300ms,强调级 ≤500ms | 【官方】Material Design 3 |
| 缓动 | 入场 ease-out、退场 ease-in、屏内 ease-in-out、进度类 linear;**禁线性匀速** | 【官方】MD3+Adobe |
| 文字出镜 | 1 秒/13 字符;最短停留 1.5s;≤2 行;一屏一个概念 | 【权威】legibility.info/SSW |

## 3. 结构模板

`钩子/问题 3–5s → 问题放大 → 解决方案/步骤(每步一场景)→ CTA`

- **画面必须直接图解旁白正在说的内容**,不做纯装饰动画(TechSmith);
- 旁白承载主信息流,屏幕文字只放关键词;**动效与旁白逐句对齐**;
- 卡片文案由 Agent 设计(需要创意),时间窗由 `wordline` 决定(脚本)。

## 4. CutFlow 对应

- 场景 = artboard 卡;`rs_artboard` 的 `manifest.json` 是工程 ↔ 产物 ↔ IR 挂点唯一映射;
- 旁白:① `rs_tts --script 文案.txt`(音色卡,逐句落盘 + 断点续传)→ `rs_dub align` 补字级;② 或 `rs_align build --media 口播素材` 用原声;
- 动效:入场 `fadeIn/slideIn` 300ms(渲染器 `motion` 枚举),卡片内按 MD3 时长;
- 字幕:`talkshow-bold`,与旁白同源;
- 音效:`assets_sfx` 转场 whoosh、要点 pop/ding。

## 5. 红线

- 文字停留 <1.5s 或 >40 字/屏 = 不可读;
- 全片同一场景超过 7s 无变化 = 掉留存;
- 动效线性匀速 = 机器人感;
- 画面与旁白不对位(说的和显的不是一回事)= 不合格;
- TTS 路径**不得**把估算出来的卡内时间当字级用(卡拉OK 逐字染色直接拒绝)。
