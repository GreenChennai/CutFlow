# videoType = `talking-head` · 纯口播

> 调研 2026-09-08(源自原 `rules/genres/口播知识.md`)。来源:【官方】YouTube 创作者频道/CapCut 创作指南/抖音创作者中心;【数据】Opus.pro 1350 万条短视频研究;【经验】Merra AI、迅课等。
> brief 已填的值优先;本册只在 brief 缺省时兜底。

## 1. 管线分支(本类型特有)

| 环节 | 做法 |
|---|---|
| **人物处理** | **绿幕必抠**:`cropTopPct` 裁顶部非绿幕区(如白墙)→ `colorkey`+`despill`(见 ADR-0003)。注意:裸 `chromakey` 在本机 ffmpeg 构建上输出人像半透明,一律走 `colorkey` |
| 背景 | 默认虚拟背景(artboard 生成,与视频同分辨率);纯色/图片可替代 |
| **字幕** | **重中之重**:`talkshow-bold`,每卡 ≤12 字(9:16)、CPS ≤9;平台见 `rules/platforms.md`。时间全部来自 `wordline.json` |
| 动画密度 | **少 或 零**(每 30–40s 一张,可选)。要更多动画 → 换 `talking-head+animation` |
| 粗剪 | **必做**:口误重录 / 中途调整仪容换提词器 / 口水词 全在 S2 剪掉(见 `rules/roughcut.md`) |
| 声音 | 原声优先;原声不可用时才走音色卡 TTS |

## 2. 节奏参数表(brief 缺省时采用)

| 参数 | 值 | 来源 |
|---|---|---|
| 视觉变化间隔 | 2–5s(跳切/推近/贴图/花字/音效都算) | 【经验+数据】"2-Second Rule";Opus.pro:变化多样性>频率 |
| 语速 | 240–280 字/分钟(快节奏 300–330) | 【经验】 |
| 单条时长 | 科普 15–30s;结构完整 50–60s;深度知识 1–3 分钟 | 【数据】法治日报引抖音/Opus.pro |
| 字幕 | 单行 ≤12 字(9:16),底部安全区,白字描边,关键词变色 | 【官方】广电总局译制规范+平台惯例 |

## 3. 结构模板

`钩子 0–3s(疑问/反差/结果前置,禁片头动画)→ 价值主体(要点×3–5,每 3–5s 一次视觉变化)→ 结尾 3–5s(下期钩子 + CTA)`

- CTA = "理由 + 动作",只主推一个动作,放在情绪最高点 1–2 秒;
- 前 30 秒留存 ≥70% 更易获推荐【数据】。

## 4. CutFlow 对应

- **跳切**:剪掉停顿与口水词(`rs_cut` 出 CutList → IR 多 clip `sourceIn` 跳接);
- 绿幕 → 虚拟背景(默认);知识/数据卡按语义节拍插入(需要时升级为 `talking-head+animation`);
- 字幕:`talkshow-bold` + `textopt` 轻改写;断句走 `segmentation` DP(连词不落卡尾);
- 音效:卡片切入 whoosh、要点 pop/ding(`assets_sfx`)。

## 5. 红线

- 字幕**无错别字、时间轴同步**(抖音低质判定硬红线);无促销/导流字样(星图规范);
- 绿幕残留 = 直接不合格(半透明人像同罪);
- 不剪粗剪 = 用户能听见口误 → 交付前必须过 `rs_cut`。
