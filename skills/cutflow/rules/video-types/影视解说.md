# videoType = `drama`（影视解说分支）· 影视解说

> M8 正式册（方案 §5.5.3 解说半边）。来源分级:【规范】YouTube Fair Use 四要素(`rules/video-types/_通用规则.md` §版权);【经验】解说类从业者共识(解说:画面 ≈ 7:3、-22dB 让位解说词)。风格包:暂无专属包(编译经 `templates/prompts/film-commentary.md` 预填,走 drama 能力集 `text.broll / sub.pair / drama.hook`)。

## 1. 素材特征(与短剧分支的根本差异)

- **叙事在解说轨里**,画面是论据而非主线;**解说:画面 ≈ 7:3**(解说音轨时长占比,机械可查);
- **关键对白必须保留原声**——解说话不说清的戏剧瞬间,原声台词自己开口;原声对白不进解说正文,字幕用引号区分;
- 引用素材是**版权雷区**:每一秒引用都要登记来源与时长,「转化性」靠原创解说撑起来(方案 R7:机械只判占比,转化性显式标 L1/用户项,不假绿)。

## 2. 节奏策略

| 参数 | 缺省值 | 说明 |
|---|---|---|
| 节奏档 | `drama`(注册表) | 卡 2–6s(解说比短剧松,给观众读屏时间);视觉节拍随剪辑点 |
| BGM | **开**,增益 **-22dB**(全库最低档) | 【经验】让位解说词;解说停顿时可显式抬 2–3dB(改 IR `bgm.gainDb` 留痕) |
| 三轨优先级 | **解说 > 原声对白 > BGM** | ducking 链:原声段压 BGM,解说段压一切 |
| 转场语法 | 硬切为主;章节切换 fade | 【经验】禁花哨转场连用(与 vlog 同规) |
| 单条时长 | 1–5 分钟 | 「N 分钟看完」式纯剧透替代 → WARN(见 §5) |

## 3. 字幕要点(本型最特殊)

- **解说词全程上屏**,`subtitle-white` 主 Style(样式走对应平台预设);
- **原声对白自动包中文引号**上屏:ASS 双 Style(--dual-style 旗标,完整命令见 §4 S7 行;主 Style=解说、`Quote` Style=引号对白,暖黄斜体可区分);对白卡切分预算预留引号位;
- 每卡字数/CPS 沿平台预设红线(9:16 ≤12 字、16:9 ≤22 字,CPS ≤9);
- B-roll 匹配走 `text.broll`:缺 CLIP 组件时降级 `keyword-match`(素材名/OCR 命中),降级必须留痕(`broll_matches.json` 的 `degraded` 块)。

## 4. 管线分支(本类型特有)

| 环节 | 做法 |
|---|---|
| S0 摄取 | `python skills/cutflow/scripts/rs_ingest.py copyright <工程根>` —— 引用素材必须登记(来源/时长/单部标识),缺登记非零退出 |
| S2 粗剪 | 引用段按「论据」选;`retake` 检测器基本不触发(正常) |
| S4 挂卡 | `python skills/cutflow/scripts/rs_broll.py match <工程根> --query <语义>` 供 B-roll 检索;降级留痕 |
| S6 音频 | 三轨优先级:解说轨 gain 0dB 基准,原声对白 -3~-6dB,BGM -22dB;ducking 生效断言见验收 |
| S7 字幕 | `python skills/cutflow/scripts/rs_subtitle.py --from-wordline <wordline> --dual-style --out <输出目录>` —— 双 Style 必开 |
| S9 体检 | `python skills/cutflow/scripts/rs_sync.py --wordline <wordline> --ass <ass> --out <输出目录> --video <成片>` —— 版权占比判据在 L0(`rs_verify`),钩子/废帧判据随 `drama.hook` 声明启用 |

## 5. 版权门禁(方案 R7:机械判占比,转化性标 L1)

| # | 判据 | 口径 | 级别 |
|---|---|---|---|
| 1 | 引用登记完整 | `copyright.json` 覆盖全部引用素材(来源+时长+单部标识) | **L0 硬判**(缺登记非零退出) |
| 2 | 单部引用占比 | ≤30%(初值,`pipeline.json params.copyrightMaxSingleSource` 可覆盖) | **L0 硬判** |
| 3 | 总引用时长占比 | ≤70% | **L0 硬判** |
| 4 | 原创解说轨占比 | ≥25%(解说型;原声对白句不计入) | **L0 硬判** |
| 5 | 转化性说明 | 交付说明书必含版权节:引用清单+转化性说明+AI 标识 | L1(文本存在性可查) |
| 6 | 「N 分钟看完」纯剧透替代 | 解说轨覆盖全片关键剧情 → WARN | L1 目测(不假绿) |

## 6. 该型验收清单(L1 目测 + 用户 L2 对照用)

- [ ] 解说:画面 ≈ 7:3(时长占比机械可查);
- [ ] 关键对白保留原声(至少 1 处引号对白卡,抽样听);
- [ ] 双 Style 字幕生效(解说体/引号体视觉可区分,ASS 双 Style 段机械可查);
- [ ] 版权门禁全过:登记完整、单部 ≤30%、总引用 ≤70%、解说轨 ≥25%(L0);
- [ ] 交付说明书含版权节(引用清单/转化性/AI 参与标识);
- [ ] B-roll 匹配 `degraded` 状态已留痕(降级 keyword-match 时如实标注)。
