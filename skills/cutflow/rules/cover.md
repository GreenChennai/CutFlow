# Cover — 自动封面

> 视频必须有封面(平台封面即点击率)。渲染完成后的标准产物:`06_output/封面.png`(1080×1920 或 1920×1080)。

## 流程(三选一,按素材自动判断)

1. **真人出镜**(口播类,优先):
   - 抽帧:口播视频 20%–40% 进度处抽 1 帧(此区间人物姿态自然、表情丰富);
   - 抠像:artboard `scripts/cutout.py 帧图 --model isnet-general-use`(BiRefNet 需联网下载,isnet 本地即有);
   - 后处理:去绿边(绿通道压回 r/b 均值)+ 裁掉画面穿杂物(PIL);
   - 合成:artboard HTML(人物 `drop-shadow` + 标题带遮罩 + 品牌徽标 + 播放键),参考 artboard-studio/cf-cover。
2. **纯动画/无人出镜**:直接用成片里信息量最大的一张卡扩展成封面(静态化),或 artboard 文字封面。
3. **用户已给封面**:校验分辨率后直接复用。

## 命名与登记
产物 `06_output/封面.png`;同步 `01_materials/MANIFEST.md` 记录抽帧来源时间点。

## 红线
- 标题 ≤10 字主标题,断行不得拆词;
- 人物不得裁头顶;抠像边缘不得有绿边(去绿边后目测);
- 封面文字避开平台角标位(右下角)。
