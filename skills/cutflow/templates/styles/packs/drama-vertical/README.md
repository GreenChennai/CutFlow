# 风格包:短剧·高燃竖屏(`drama-vertical`)

> ADR-0051 风格包;registry `drama-vertical` 条目的参数真身。方案 §5.11 的 drama-vertical 提示词模板挂在本包。

## 调性

强冲突、快翻转、情绪外放。前 3 秒给冲突不给背景;台词短促、字幕跟台词;配乐负责把情绪推上去。卡片视觉借 artboard `ecommerce-promo`(大字报强对比),钩子标题卡与"爽感"同源。

## 适用

- videoType:`drama`(竖屏短剧/剧情片段/系列微剧);
- 平台/画幅:抖音 9x16(单集 1–3 分钟量级);
- 不适用:口播讲剧(影视解说去 film-commentary 模板)、真人日常记录(去 vlog-douyin)。

## 禁则(≥5 条,每条带理由)

- **禁背景铺垫开头**(前 3 秒讲设定不讲冲突)—— 理由:短剧前 3 秒定去留,背景铺垫=划走;开场必须是冲突/悬念/反转前置;
- **禁字幕压台词节奏**(CPS 超 9 或单卡超 14 字)—— 理由:观众要同时看表演和读字幕,CPS≤9 全库红线,14 字是竖屏台词卡上限,超了必有人弃剧;
- **禁配乐盖台词**(对白段 ducking 不生效仍硬铺)—— 理由:短剧信息在台词,配乐是情绪推手不是主角,对白段必须让频;
- **禁剧透式预告卡**(下集预告把反转说破)—— 理由:预告卡的任务是造悬念不是复述剧情,说破反转=自断下一集完播;
- **禁节拍特技转场**(snapToBeat 类踩点用在剧情片)—— 理由:剧情转场服务叙事节点(时空转换 fade / 爽点翻转 slide),音乐踩点特技会消解严肃感;
- **禁无钩子收尾**(片尾平淡出黑)—— 理由:短剧是系列生态,尾卡必须带下集悬念句,否则断掉追更链。

## 参数出处速查

| 字段 | 值 | 出处 |
|---|---|---|
| pacing | fast(卡 900–3500ms,节拍 2–3s) | [内部] registry.pacingTiers.fast;[经验] 短剧节奏同档 |
| bgm | 开(-18dB,对白段 ducking) | [经验] 配乐铺情绪,台词优先 |
| subtitle | subtitle-white / 14 字 / CPS 9 | [经验] 台词 14 字竖屏上限;CPS 全库红线 |
