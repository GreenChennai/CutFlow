# 风格包:混剪卡点·抖音竖屏(`mixcut-douyin`)

> ADR-0051 风格包;registry 同名条目的参数真身。方案 §5.11 的 mixcut-beat 提示词模板挂在本包。

## 调性

音乐驱动、高密度、踩点切换。BGM 是时间轴骨架,画面事件跟节拍走;字幕只做点睛,不做翻译。卡片视觉借 artboard `ecommerce-promo`(大字报高饱和强对比),片头钩子卡与高燃调性同源。

## 适用

- videoType:`混剪`(卡点/音乐驱动;无旁白主线);
- 平台/画幅:抖音 9x16,单条 15–45s(混剪.md §2,宁短勿长);
- 不适用:有完整口播稿的解说(去 knowledge-talkshow-douyin / film-commentary 模板)、日常碎片(去 vlog-douyin)。

## 禁则(≥5 条,每条带理由)

- **禁静态长镜头进卡点**(单镜头超 2.4s 上限)—— 理由:music 档卡时长 0.8–2.4s,静态素材踩不住鼓点,节奏一断完播崩(混剪.md §1:静态素材选材阶段就该筛掉);
- **禁逐句歌词刷屏**(字幕超 lyricOnly 点睛范围)—— 理由:卡点型字幕是强调不是翻译,逐句上歌词观众来不及读,CPS≤9 红线也必破(混剪.md §3);
- **禁 0.3s 内连续双转场** —— 理由:转场要落拍点,连闪两次既脏又抢重拍,抽查副歌 10 个拍点 ≥8 个对齐才过验收(混剪.md §5);
- **禁无授权 BGM**(来源不明音轨直接铺)—— 理由:BGM 是本型的时间轴骨架,版权四要素全库纪律,无授权源=全片不可发布;
- **禁重拍处 impact 音效连用**(>2 个/15s)—— 理由:音效会打架 BGM,重拍处最多 impact ≤2 个/15s(混剪.md §4 S6);
- **禁转场特技压过素材**(slide/circleopen 全片连用)—— 理由:硬切是主语法,特技只在段落切换点缀;连用即"模板感",掉质感。
