# 风格包:录屏教程(`screen-tutorial`)

> ADR-0051 风格包;registry `screen-tutorial` 条目的参数真身。方案 §5.11 的 screen-tutorial 提示词模板挂在本包。

## 调性

跟操作、降噪、导航感。录屏本体即内容,解说是导航,卡片是路标;节奏由操作步骤决定,不由音乐决定。卡片视觉借 artboard `data-longform`(报告型步骤语言),章节卡与操作分段同构。

## 适用

- videoType:`screen-recording`(软件操作/工具演示/流程教学);
- 平台/画幅:B站 16x9(中长教程;抖音快节奏软件种草去 knowledge-talkshow-douyin);
- 不适用:口播讲解型教程(去 tutorial-bilibili)、无操作演示的纯剧情内容。

## 禁则(≥5 条,每条带理由)

- **禁节奏快过跟读速度**(节拍 <3s 或卡时长 <2.5s)—— 理由:观众要边看边跟操作,slow 档是底线,快了等于让人暂停做笔记;
- **禁 BGM 默认铺底** —— 理由:录屏讲解的清晰度是第一优先级,系统提示音/键位音与 BGM 打架会直接毁掉教学价值;显式开也不越过 -20dB;
- **禁卡片遮挡操作区**(光标/菜单/输入框区域)—— 理由:观众眼睛跟着光标走,卡片入侵操作区=遮住答案;安全区机检之外还要人工过一遍光标轨迹;
- **禁步骤跳号**(章节卡编号断档)—— 理由:教程可信度来自完整步骤链,跳号观众就要暂停猜,弹幕刷"少了一步";
- **禁低分辨率录屏上 16x9**(拉伸放大)—— 理由:文字模糊是录屏教程的死刑,素材低于 1080p 必须在 S0 就拦截而不是硬拉;
- **禁每卡超过 22 字 / CPS 超 9** —— 理由:22 字横屏单屏上限,CPS≤9 全库红线;操作术语长,超限必跳读。

## 参数出处速查

| 字段 | 值 | 出处 |
|---|---|---|
| pacing | slow(卡 2500–7000ms,节拍 3–5s) | [内部] registry.pacingTiers.slow |
| bgm | 关(-20dB 仅显式开时生效) | [经验] 录屏降噪优先 |
| subtitle | tutorial-clean / 22 字 / CPS 9 | [内部] platforms.bilibili + tutorial 系 style |
