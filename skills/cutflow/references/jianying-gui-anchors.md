# 剪映 5.9 GUI 锚点备忘(computer-use 实测,已验证导出闭环)

> 5.9 的 AX 树元素多为匿名(text 1 / button 2),**以截图坐标 + 固定布局为主**,每步截图留证。
> 2026-09-07 实测:草稿打开 ✓、Ctrl+E 导出 ✓、产物 mp4 ✓。

## 已验证导出流程(首选)

1. 关闭剪映 → rs_jy_draft 写草稿+注册 → 启动 5.9(约 10s 就绪)→ 首页草稿卡双击进入编辑器;
2. **按 Ctrl+E**(比点按钮可靠;顶部导出按钮随窗口尺寸/最大化状态漂移,截图坐标易失效);
3. 导出弹层(640x663):标题/导出至(C:/Users/<u>/Videos 默认)/1080P/推荐/H.264/mp4/30fps/Rec.709;
4. 点弹层右下「导出」(约 x=80%,y=96%)→ 等待完成 → 产物在导出目录,移入 06_output/。

## 状态机

home(首页)→ edit(编辑器,标题=<草稿名>)→ pre_export(导出设置弹层)→ exporting → done。

## home

- 弹窗:首启"开启推送通知" → 「暂不」在弹窗右侧按钮。
- 开始创作:顶部渐变大按钮(约窗口宽 62%,高 15%)。
- 草稿列表:中下部;双击草稿卡进入编辑器;**rs_jy_draft 注册的草稿会正常出现在列表**。

## edit

- 编辑器就绪标志:时间线可见文本轨(字幕块)+视频轨缩略图;草稿参数面板 1080P/30帧/Rec.709。
- 窗口尺寸会在首页/编辑器间变化,**每次点击前必须重新截图定位**;优先用快捷键。

## 已知坑

- 息屏截图可用(不依赖物理显示器)。
- 11.3 永不操作(草稿加密);5.9 禁自动更新。
- 写草稿前必查 JianyingPro.exe 未运行;关闭剪映用 taskkill(无 //F)可能有子进程残留,收尾时 //F 兜底。
