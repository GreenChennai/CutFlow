## 二、对齐增强(ADR-0030)

### 方法
ASR 字级时间戳存在系统性偏移(引擎延迟/时间基)与句边界局部误差。`calibrate` 用音频 RMS 能量包络(10ms 窗,纯 stdlib)定位每句的**连续活跃段**(50ms sustained)能量起点,在 ±250ms 窗内与时间戳比对,偏移 ≥20ms 才修正(抗抖动)。修正写回 wordline(域内同步 src* 字段),守单调性,重算 gaps。

### 验证
- 合成素材(4 句语音包络 + 整体 +150ms 偏移):中位偏差 140ms → **0ms**,4/4 句修正
- 无偏移素材:0 句修正(抖动保护)
- 静音素材:显式降级说明;损坏文件:`PCM_EXTRACT_FAIL` 明确报错
- `wordline.calibration` 报告落盘(逐句修正量/前后偏差),审计可见

### 与门禁的关系
`rs_sync` 门禁(median ≤40ms / p95 ≤80ms)不变;calibrate 在门禁**之前**运行,让门禁更常直接通过。S1 注册表加 `post` 步骤自动执行,零操作成本。

## 三、绿幕键控 v2(ADR-0029)

### 根因与修法

| 缺陷 | 根因 | v2 修法 |
|---|---|---|
| 黑边 | despill 在 RGB 域钳 G,边缘混合像素被压暗 | 溢色只在色度平面向中性收,R/B(Y 平面)永不触碰 |
| 暗场 | colorkey RGB 欧氏球对亮度不免疫,暗角绿键不掉 | `G/max(R,1)` 比值判据,亮度缩放完全免疫 |
| 吃边 | 混合像素近二值丢弃 + 腐蚀链吞半透明带 | 二值 matte → matte blur 空间平均 → YUV 域 alpha 感知去混合 → alpha 曲线收紧 |

### 量化对比(1280×720,难例:暗角 45%/投影 60%/4:2:0 欠采样;工具 tests/rs_chroma_bench.py)

| 指标(越低越好) | v0.10-0.12 | v2 | 变化 |
|---|---|---|---|
| alpha MAE(全图) | 22.6 | 12.5 | **-45%** |
| 黑边 fringe%(均匀光+420) | 4.9 | 0.0 | 清零 |
| 黑边 fringe%(投影+420) | 23.3 | 7.7 | -67% |
| 暗场 darkhole%(投影+420) | 0.09 | 0.0 | 清零 |
| 边缘误差 p95(均匀光+420) | 48.5 | 40.2 | -17% |
| 边缘误差 p95(投影+420) | 94.9 | 71.1 | -25% |
| 边缘保留率 1-eaten(even+420) | 6.8% | 57.4% | **8.4×** |

目检要点(新旧合成对照帧存 `.cluster/bench/`):
- 旧链:边缘整圈深色硬边、投影区背景暗块、发丝成块丢失
- 新链:边缘过渡平滑、头发丝可见、投影区干净、发际无紫边(色度修正钳 ±40)

### 保护性难例回归(tests/test_v13.py)

- 绿色服饰(绿衣 dline≈11 vs 背景混色 ≤2):混合线距离第二判据(OR)救回,透率 2.79%
- 蓝幕:主导通道自动切换,背景残留 <2%
- 光照不均(暗角 0.45):背景残留 <0.5%,旧链在投影场景有暗场残留而 v2 为 0
- legacy 回退:`keyMode="legacy"` 全链可用(v0.10-0.12 行为)

## 七、已知限制(诚实清单)

- 绿色/蓝色服饰与幕布同色系时存在键控固有歧义,极端场景建议换幕布色(keyDistCut 可缓解大部分)
- 极暗幕布(亮度 <40/255)色度信噪比不足,任何色度键控都会退化(制作端 checklist 已有幕布亮度要求)
- v2 键控性能约为旧链 3-5 倍(双 geq),离线渲染管线无感
- TTS 路径(纯文案)不走 calibrate(无原始人声可测),字幕对齐依赖 TTS 实测时长(与 v0.12 一致)
