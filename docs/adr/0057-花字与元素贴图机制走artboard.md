# ADR-0057: 花字与元素贴图机制（走 artboard，不自研渲染）

日期: 2026-09-26 - 状态: 已采纳(v0.20 已落地) - 来源: 《CutFlow-迭代计划-v2-20260925》主册 §3(转写自桌面蓝本,以蓝本为权威)

**状态**：已采纳(v0.20 已落地) · **关联**：ADR-0005（趣味素材路线）、v1 ADR-0017（artboard 桥）、ADR-0053

#### 背景

现状（分册03 已核）：**没有真·花字**——`rs_subtitle` 只产普通 ASS 样式（描边/阴影/对齐），**无底衬、无逐字动画**；**没有贴图/元素库**，唯一路径是 artboard 生成透明 PNG 挂 overlay 轨；vendored `pyJianYingDraft` 有 `StickerSegment`/`TextEffect`，但**需 resource_id 且无离线来源**，管线未使用。

#### 决策

1. **花字分两档，都不自研渲染**：

| 档 | 做法 | 适用 |
|---|---|---|
| **花字（基础档）** | **ASS 富文本**：底衬（`\bord` + 背景框 `\p1` 绘制）、逐字/逐词动画（`\t` + `\fad`）、双 Style（沿用 v1 的 `--dual-style`） | 关键词强调、标题字、金句 |
| **花字（进阶档）** | **artboard 卡片**：把花字做成 artboard 场景卡（模式 S），导出 MP4/PNG 挂 overlay 轨 | 片头/标题/章节的复杂花字 |

2. **不做剪映 `resource_id` 花字**：`resource_id` 是剪映云端资源标识，**无离线来源**，且 6.0+ 草稿加密（v1 ADR-0044 / ADR-0052 已定）。**明确不实现**并写入文档。
3. **元素贴图（`assets/elements/`）**：
   - 存放**透明 PNG / 序列帧 / 短 MP4**；
   - 通过既有 `rs_ir add-overlay` → `rs_render.step_compose`（消费 `clip.overlay={x,y,w,h,opacity}`）挂轨；
   - **不新增渲染通道**——沿用 v1 已定的 overlay 轨；
   - 新增 `rs_asset.py`（见分册01）负责索引、检索、许可校验、入轨。
4. **元素必须过安全区**：沿用 ADR-0009 硬约束（9:16 左右 184 / 顶 230 / 底 576），越界即报错。

#### 取舍

- 付出：花字上限受 ASS 与 artboard 表达能力限制（做不到剪映那种 GPU 粒子花字）。
- 换来：**零新增渲染通道**、零重依赖、与 artboard 复用同一条链；不承诺做不到的东西。

#### 被否决的替代

- **自研花字渲染器（FreeType + 自绘描边/底衬/动画）**：否决——重造轮子，且 artboard 已是现成的 HTML/CSS 渲染器。
- **买/抓剪映 resource_id**：否决——版权与合规风险，且 6.0+ 加密后不可用。
- **花字直接用 Lottie**：**保留为候选**（Lottie→MP4 可用 `puppeteer`+`lottie-web` 经 artboard 走），需一手核实许可证与体积后决定（见分册05 风险）。

#### 四问

| 问 | 答 |
|---|---|
| **旧工程怎么办** | 纯新增：花字基础档是 ASS 富文本（不改变现有普通字幕路径，`--huazi` 开关默认关）；元素走既有 overlay 轨。 |
| **门禁怎么把守** | ①`tests/test_huazi.py`：ASS 富文本关键字符（`\bord`/`\t`/`\fad`）存在；**任何 ASS Dialogue 文本匹配前必须剥 `{...}` override**（既有硬规则 18，测试复用）；②`tests/test_assets.py` 的元素入轨与安全区校验。 |
| **怎么验收** | 一条工程：同一句话分别出「普通字幕 / 花字基础档 / 花字 artboard 档」三种，肉眼可辨并过 CPS/字数红线。 |
| **怎么回滚** | `--huazi` 关闭即回到普通字幕；artboard 卡删除即回滚。 |
