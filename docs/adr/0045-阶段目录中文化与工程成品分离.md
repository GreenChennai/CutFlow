# ADR-0045: 阶段目录全量中文化 + 工程区与成品区物理分离

日期: 2026-09-25 · 状态: 已采纳（待落地） · 关联: ADR-0007（修订）、ADR-0034（契约不变）、ADR-0052（成品定义）

## 背景

ADR-0007 定「用户产物中文命名、内部件 ASCII」。实际执行成了**内部目录也全 ASCII**，导致：中文用户无法从目录名判断「哪个是工程、哪个是成品」；交付物与中间件在 `06_output/` 顶层混放（§1.4b）；`rs_cleanup.py` 只能靠白名单补丁区分。

## 决策

1. **阶段目录全量中文化**，文件名**保持 ASCII 不变**（完整映射表见 §4.2）：

| 旧名 | 新名 | 说明 |
|---|---|---|
| `00_brief` | `00_制作简报` | `brief.md` / `terms.txt` / `intent_decisions.json` / `cards.json` |
| `01_materials` | `01_原始素材` | 只读 |
| `02_sensed` | `02_转写与校对` | 顺带**删除遗留 `frames/` 子目录** |
| `03_assets` | `03_创作素材` | artboard 卡片／配音／BGM／音效／背景 |
| `04_cut` | `04_粗剪决策` | `cutlist.json` / `cut_report.md` / `review/` / `rebuild.py` |
| `05_ir` | `05_时间线工程` | `project.json` / `wordline.json` / `variants.json` / `pipeline.json` / 剪映草稿 |
| `06_output` | `06_成片输出` | **母版** + 全部中间件（工程侧，可重建） |
| `_state` | `_内部状态` | `S*.json` / `verify.json` / `backup/` |
| — | **`成品/`** | **新增交付区**（与阶段目录平级，独立子树，只读语义） |

2. **`成品/` 交付区只放不可编辑的最终产物**（见 ADR-0052）。
3. **删除废弃目录**：`04_ai_prompts`、`02_sensed/frames` 停止创建；`ensure_workdir` 清理。
4. **`06_成片输出` 不再承载交付语义**。它是「母版 + 中间件」，`成品/` 才是交付。

## 取舍

- 付出：一次性的改名成本（60+ 处字面量）与 cutforge 同步改造成本。
- 换来：目录自解释（中文用户零学习成本）；工程／成品有物理边界（可安全清理工程区而不担心丢交付）；`rs_cleanup` 白名单可以简化。

## 被否决的替代

- **只把顶层两个容器中文化**（`工程/` + `成品/`）：否决——内部仍中英混杂，不满足「主要用中文区分名字」。
- **靠 junction 永久兼容英文目录**：否决——永久别名就是永久技术债（违反 G9）。
- **同时中文化文件名**（如 `项目.json`）：否决——五份 schema 与 cutforge 契约（`additionalProperties:false`、`target.file` 封闭枚举）都以 ASCII 文件名为准，改动面失控且无收益。

## 影响

- 新增 `rs_paths.py` 为唯一真相源（ADR-0046），15 个脚本 60+ 处字面量全部改为查表。
- cutforge 需同步：`scaffold.rs`（空工程模板）、`stage.rs`（脏传播路径）、`tools/gates/gate.py`、`docs/FLOW.md` L63–78、`tests/test_bridge_smoke.py`。
- 文档面：`SKILL.md` §7 目录契约、`rules/*.md` 全部命令示例、`README.md`、`CONTEXT.md`。

## 四问

| 问 | 答 |
|---|---|
| **旧工程怎么办** | `tools/migrate_paths.py <工程>` 一键迁移（见 §4.6）。改名 + 写 `迁移报告.md` + **保留过渡期 junction 只读别名**（默认保留 2 个发布周期，到期移除并在 CHANGELOG 喊）。 |
| **门禁怎么把守** | 新增 **`tests/test_paths_gate.py`**：①扫描全仓，`scripts/` 下**不得出现阶段目录字面量**（白名单仅 `rs_paths.py`）；②`rs_paths.STAGE_DIRS` 与实测磁盘结构一致；③迁移脚本对夹具工程幂等。 |
| **怎么验收** | 迁移夹具工程（talking-head / pure-animation / vlog / 混剪 各一）→ 迁移前后 `rs_verify` / `rs_run --status` / cutforge `cargo test` / 四桥冒烟 **全绿**；`--status` 报告「无 stale」。 |
| **怎么回滚** | `migrate_paths.py --rollback <工程>`（改回英文名 + 删 junction + 恢复记录）；迁移前自动全量备份到 `_内部状态/backup/migrate-<ts>/`。 |
