# ADR-0014:一条龙阶段补齐(品牌变体 / 音效落点 / 文案生成)

状态:已采纳 ｜ 日期:2026-09-10

## 背景

用户反馈「不够一条龙,需要 基础素材 → 粗剪处理 → 基础合成 → 动画/其他信息添加 → Logo 添加(比如一个视频需要放不同的 Logo 分别导出) → 音效添加 → 字幕合成 → 封面合成 → 文案生成(标题+简介+Tag)等等」。

对照审计:粗剪完全不存在(ADR-0012 已补);**Logo 层与文案生成完全不存在**;封面虽已实现但未纳入编排;动画卡片与音效的落点全部靠手动。

## 决策

### 1. S5 品牌层与变体矩阵

- 新增 `03_assets/branding/logos/` 与 `05_ir/variants.json`;
- 变体 = `logos × ratios × durations` 笛卡尔积(可手动排除个别组合);
- **渲染策略:共享中间件,只分叉最后一步** —— `base/composed/mixed/subtitled` 各算一次,每个变体只做 logo overlay + encode。**2 Logo × 2 比例 = 4 个成片,成本约 1.3 倍单变体**;
- 落点 `anchor ∈ {topLeft, topRight, bottomLeft, bottomRight, watermark}`,**默认避开字幕带**(9:16 底部 25%,ADR-0009);`scale` 为占画幅宽度比例而非像素,保证同一份配置在两种比例下都成立;
- 产物命名**必须带 variantId**(ADR-0007):`成片_竖版_A_最终.mp4`;
- `matrix[].backends` 声明后端能力;剪映 5.9 缺特性(如 chroma)自动降级并在交付说明标注。

### 2. S6 音效自动落点

- 落点规则显性化:转场→`whoosh`/`swipe`;强调→`ding`;列举(第一/第二/第三)→`click`;章节→`riser`/`bell`;结尾→`bell`;
- **密度硬约束:每 15s 内音效 ≤2 个**,超出按 章节/转场 > 强调 > 列举 > 氛围 优先级保留;
- 被丢弃的候选写入 `sfx_dropped.md`,**不静默丢弃**;
- 落点吸附到 **Wordline 锚点字**时间(偏差 ≤1 帧),人声侧链优先,音效 `gainDb ≤ -12`;
- 流程:Agent 出草案 → 人审 → 合并进 IR `audio.clips[]`(`role: sfx`)。

### 3. S9 文案生成

- 新增 `rs_meta.py`,输出 `metadata.json` + `metadata.md`;
- 平台规范内置:抖音(标题 ≤30 且前 8 字含钩子 / 简介 ≤55 / 5 个话题)、B站(标题 ≤80 / 分段简介 + **时间戳章节** / 10 tag)、视频号(≤22 / ≤120 / 3–5);
- **章节时间戳直接从 `markers[]` 生成**——markers 跟着 Wordline 走,经 `map_src_to_final()` 后**粗剪/调序/换 TTS 都自动正确**,不需要重新数;
- 分工:**标题/简介由驱动本技能的 Agent 本人撰写**(不接外部 LLM API);`rs_meta.py` 负责校验、截断、生成章节与落盘。未提供时输出占位并标 `needsAgent: true`,不猜内容。

### 4. 编排层

S0–S10 阶段注册表直接对应用户原话的顺序;封面(已有 `rules/cover.md`)正式纳入 S9;交付纳入 S10。

## 后果

- 一次编排出全部交付物:多变体成片 + 封面 + 平台文案 + 章节;
- 「一条龙」不等于「一口气」:阶段门禁 + 可中断恢复,可在 S2 停手改 CutList,也可在 S7 停手改一个字,都不重跑上游;
- 变体矩阵会增加产物文件数量,`deliverables.md` 必须列清"哪个文件对应哪个变体";
- 文案质量依赖 Agent 的写作能力而非脚本——脚本只保证**格式与约束**,不保证**内容**;因此 `needsAgent` 标记必须显式暴露,不能假装已完成。
