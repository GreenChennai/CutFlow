# ADR-0059: 效果用法处方与使用率门禁

日期: 2026-09-26 - 状态: 已采纳(v0.20 已落地) - 来源: 《CutFlow-迭代计划-v2-20260925》主册 §3(转写自桌面蓝本,以蓝本为权威)

**状态**：已采纳(v0.20 已落地) · **关联**：ADR-0054（分级与目录）、ADR-0055（零静默吞能力）、v1 ADR-0026（转场三级语法）、artboard `references/animation.md` §九

#### 背景

ADR-0054 把可执行档从**现有 5 条**扩到 **≈192 条**（剪映清单 T1 ≈130 + 标准 NLE 补充 62 + T2 20–30）。但**「能做」不等于「会用」** —— 用户明确提出：

> **「既然有转场/入场/出场等特效，相关视频剪辑也应该要用上，别到时候虽然有特效但是完全没用上就没意义了。」**

这是**真实的工程风险**，且有**两个失败端**：

| 失败端 | 表现 | 现有机制为何拦不住 |
|---|---|---|
| **不用** | 全片硬切到底，192 条一条没上 | 现有门禁只查「效果渲染正确性」，**从不检查"用了几处"** |
| **滥用** | 每 2 秒一个花哨转场，观感廉价 | 分册01 只有音效密度约束（15s/≤2），**转场与入场出场无任何密度上限** |

同时，项目**已有大量"手法知识"但与"效果"没接上**：v1 §5.9 的 25 条手法、`rules/editing-grammar.md`、artboard §九 的入场/出场三原则，都只写"怎么做"，**没写"什么时候该用、用哪个"**。

#### 决策

1. **确立第一原则**：**效果服务于叙事，不是装饰**。硬切是默认值，特效是例外；**每一处显式效果都必须带能一句话解释的 `reason`**（`rs_edit` 的 EditOp 已强制 `reason` 字段，本 ADR 赋予它**评审效力**）；`reason` 为"好看"类词视为未解释。
2. **采用「无技巧转场 vs 技巧转场」作为转场决策框架**（中文影视剪辑理论的经典分类）：
   - **无技巧转场 13 类**（相似体 / 承接因素 / 两级镜头 / 特写 / 声音 / 空镜头 / 主观镜头 / 挡黑镜头 / 运动动势 / 反差 / 逻辑 / 隐喻 / 相同主体）→ **靠 Agent 语义与素材选择实现，不用特效**；
   - **技巧转场**（特效）→ 只用在**时空大幅跳跃 / 叙事段落切换 / 风格化表达**三类场景；
   - 明确纪律：**Agent 的第一反应应是「这里能不能用无技巧转场」，而不是「这里加个什么转场」**。
3. **密度上限进机械门禁**（新增 `tests/test_effects_usage.py`，九条判据）：显式转场 ≤1 处/8s 且全片 ≤ 片长÷10；**花哨类 ≤3 处/片且不连续两处**；同效果 10s 不重复；每处必须有 `reason`；光敏安全；时长零漂移。
4. **每个风格包必须声明 `effects_prescription`**（处方）：`transition/in/out/sfx` 的 `min`/`max`、`prefer`、`forbid`、`flashy_max`、`require_reason`。**处方是门的依据，也是"少用也合格"的合法出口**（纯口播/纯动画的 `min` 可为 0）。
5. **效果从开工前就被规划**：`rs_intent compile` 在 `plan.json` 产出 **`effects_plan`**（按处方 + 纸面结构生成"该在哪些位置用什么"的草案），并进 `decision_log` 留痕。
6. **把"用没用上"变成 Agent 每轮可见的待办**：`rs_edit context` 的「可用特效」段升级为**「本工程该用的特效」**，显示**进度与缺口**（如「入场 0/2，缺」）。
7. **新增门禁 `EFFECTS_UNUSED`**：对**声明了处方**的风格，成片若达不到 `min` → 红。**这条直接回答用户的担心**。

#### 取舍

- 付出：每个风格包要写处方（一次性，数据量小）；`rs_verify` 多一组判据；Agent 改片时多一步"效果规划"。
- 换来：**「有特效却没用上」变成机械可见的红灯**；同时把"滥用"也一并堵住；25 条手法知识与 192 条效果终于接上。

#### 被否决的替代

- **只写文档、不设门禁**：否决——这正是现状的病根：`rules/` 里写了很多"应该这样剪"，但**没有任何机制检查它有没有被遵守**（分册03 R30 同根因）。
- **强制高使用率**（如"每 8s 至少 1 处转场"）：否决——会直接导致滥用，且与 §6.6「少即是多」（Dune）、纯口播/纯动画的正当做法冲突。**处方分档 + `min` 可为 0** 才是正解。
- **只靠 L1 目测**：否决——L1 是抽帧目测、成本高且不稳定；`EFFECTS_UNUSED` 这类计数必须机械。
- **把处方写死在代码里**：否决——违反 ADR-0018「videoType 不进代码分支」；处方必须是数据（风格包）。

#### 影响

- `templates/styles/packs/<slug>/params.yaml` 新增 `effects_prescription` 段（7 类风格包全要写）。
- `tests/test_effects_usage.py`（新，九条判据）、`tests/test_stylepack.py`（扩：处方字段完整性）、`tests/test_intent_effects.py`（新：`effects_plan` 生成）、`tests/test_editing_grammar.py`（新：决策树与 13 类映射表存在）。
- `rs_verify` L0 新增 `EFFECTS_*` 判据族；`rs_intent` 产出 `effects_plan`；`rs_edit context` 增「该用的特效」段。
- `rules/editing-grammar.md` 新增「用法层」章节（决策树 + 决策表 + 处方）；`rules/edit-op.md` 新增「`reason` 的写法」。
- `rules/verify.md` 的 L1 清单补 5 条（分册06 §9.5）。

#### 四问

| 问 | 答 |
|---|---|
| **旧工程怎么办** | 无 `effects_prescription` 的风格包 → **处方门禁不生效**（跳过并 WARN `NO_PRESCRIPTION`），旧工程行为不变；**只有声明了处方才受约束**。 |
| **门禁怎么把守** | ①`tests/test_effects_usage.py` 九条判据（`EFFECTS_UNUSED` / `EFFECTS_OVERUSED` / `EFFECTS_REPEATED` / `EFFECTS_UNMOTIVATED` / `SFX_DENSITY` / `FLASH_UNSAFE` / `DURATION_DRIFT`）；②`tests/test_stylepack.py` 校验 `min ≤ max`、`prefer ∩ forbid = ∅`；③`test_editing_grammar.py` 校验 13 类无技巧转场都有映射或明确"无需特效"。 |
| **怎么验收** | 四型各出片：`EFFECTS_UNUSED` 不出现；混剪的花哨类 ≤3 且不连续；**纯口播 `flashy_max=0` 且有片证明"少用也合格"**；抽 3 处转场每处能一句话解释；`forbid` 的效果零出现。 |
| **怎么回滚** | 处方是风格包里的数据段；删除即回到"无处方"（门禁跳过）。**注意**：回滚等于放弃"效果是否被用上"的保障，属**主动降级**，须在 CHANGELOG 写明。 |
