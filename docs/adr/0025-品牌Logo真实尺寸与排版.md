# ADR-0025:品牌 Logo 真实尺寸探测与排版规则

状态:已采纳 ｜ 日期:2026-09-14(v0.10,用户反馈#4)

## 背景

Logo 功能 v0.9 就是半成品:`rs_brand.variant_ir` 产出 `clip.overlay={x,y,w,h}`,但 `rs_render` 根本不消费该字段——Logo 会以 scale 默认值**贴满画布**(潜伏致命,只是此前没有工程带 Logo 轨所以未爆)。`probe_logo` 存在但从未被调用;`logo_rect` 假定 Logo 是方形(非方 Logo 全部变形);anchor 只有 5 位且不避字幕带;alpha 探测还有 `"alpha" in fmt` 对 rgba 永远 False 的子串匹配 bug。

## 决策

1. **真实尺寸 = 像素宽高 + alpha 内容包围盒**:`probe_logo()` 读 ffprobe 宽高与 pix_fmt(修复 alpha 判定:`rgba/bgra/argb/abgr` 前缀或 `yuva`/`pal8`),有 alpha 时用 `alphaextract` 抽取 alpha 平面扫描**内容包围盒**——透明 padding 不算尺寸,视觉大小才参与排版。`rs_brand.py --analyze <logo>` 输出诊断,供 Agent 在 brief 阶段核对素材。
2. **排版按真实宽高比**(`logo_rect()`,rules/branding.md §3):`scale` 默认 0.12 → 占画宽比例求目标宽;高按**内容宽高比**求出,不再假定方形;高度上限 8% 画高(超限按高等比缩宽),防角标压人物/标题;margin 4% 画宽。
3. **锚点 6 位 + 字幕带避让**:`topLeft/topRight/bottomLeft/bottomRight/topCenter/bottomCenter`;bottom 系自动抬升到字幕带(9:16 底部 25%)上缘再留 margin,返回值 `lifted=true` 留痕——交付说明必须写"Logo 已避开字幕带"。
4. **渲染契约闭合**:`variant_ir()` 产出变体轨 clip 带 `overlay={x,y,w,h,opacity}` **绝对像素落点**;`rs_render.step_compose()` 消费该字段(scale/position 二选一,overlay 优先),`opacity<1` 走 `colorchannelmixer=aa=`。字段必须有人消费——渲染器不认领的字段在 validate 层报错,不再允许"产而不消"。
5. `check_safe_area()` 补 x 方向与四边越界检查;`canvas_for()` 查表 `rs_common.RATIOS`,禁止本地硬编码画幅。

## 后果

- Logo 按真实比例、真实内容大小落位,四角/顶底排版可预期,永不压字幕带;
- 多变体矩阵(Logo×画幅×时长)笛卡尔积复用既有变体轨机制,不新增轨型;
- 排版参数(scale/anchor/margin)是声明式的——改参数重跑 variant 即可,不用动渲染器;
- 非 rgba 但实际带透明的异格式(pal8 伪透明等)走包围盒失败退整图路径,不阻塞,但尺寸按整图算——brief 阶段用 `--analyze` 提前发现。
