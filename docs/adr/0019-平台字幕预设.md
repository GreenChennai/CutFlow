# ADR-0019:平台字幕预设与画幅单一事实源(含 1080×1440)

状态:已采纳 ｜ 日期:2026-09-12（v0.7.1）

## 背景

用户要求:「字幕是重中之重,必须在竖屏和横屏下都有很好的观感,要兼容小红书 / 视频号 / 抖音 / B站等视频网站」。

旧实现有三个结构性问题:

1. **画幅散落硬编码**:`rs_render.RATIO`、`rs_subtitle.STYLES[ratio]`、`rs_brand.variant_ir` 的画布字典、`rs_ir.CANVAS` + 白名单 `(x, y) not in ((1080,1920),(1920,1080))`、`project.schema.json` 两处枚举、`rs_artboard.SIZE_BY_RATIO`、`rs_jy_draft` 用 `width == 1080` 反推比例 —— 加一档要改 7+ 处,漏一处就静默出错;
2. **校验口径错**:`rs_subtitle.py` 与 `rs_verify.py` 无论什么比例都取写死的 `CPS_MAX["9x16"]`;
3. **平台差异无处可查**:安全区/字号/每卡字数只能靠人记,不在任何数据里 —— 而"字幕观感"恰恰是这组参数决定的。

## 决策

1. **画幅单一事实源**:`rs_common.RATIOS = {"9x16": (1080,1920), "3x4": (1080,1440), "16x9": (1920,1080)}` + `canvas_for()` / `ratio_for_canvas()`。所有模块(`rs_render` / `rs_brand` / `rs_ir` / `rs_artboard` / `rs_jy_draft` / `rs_verify`)**只查表**,禁止 `canvas == "1080x1920"` 这类字符串比较。
2. **平台预设档案** `templates/platforms.json`:每平台一条 `{label, ratio, canvas, style, maxChars, cpsMax, safeArea{top,bottom,left,right}, coverSize, durationHint, note}`。
   首发四平台:抖音(`douyin`,9x16,底 25%/顶 12%)、视频号(`shipinhao`,9x16,左右 9%)、小红书(`xiaohongshu`,**3x4**,底 18%/顶 10%,每卡 15 字)、B站(`bilibili`,16x9,tutorial-clean,底 16%/顶 8%,每卡 22 字)。
3. **新增第三画幅 1080×1440(3:4,小红书)**:`segmentation.MAX_CHARS` 加 `3x4=15`、`CPS_MAX` 加 `3x4`;`rs_subtitle.STYLES` 三档样式补齐 `3x4` 的 `size`/`margin_v`;`project.schema.json` 的 canvas 枚举加 `1440`、outputs 枚举加 `3x4`;`rs_ir.validate` 白名单改查表。
4. **`rs_subtitle --platform`**,优先级:**显式 `--style/--ratio/--canvas/--max-chars` > 平台预设 > 内置默认**。未知平台名**直接 `BAD_PLATFORM` 报错**,不静默退回默认 —— 否则会悄悄出一版错规格的片子。为此 `--style` 默认值改为 `None`(否则无法区分"用户没给"和"用户要默认")。
5. **CPS 口径按比例取**:新增 `segmentation.cps_max_for(max_chars)`,替代 `rs_subtitle`/`rs_verify` 里的 `CPS_MAX["9x16"]`;`rs_verify` 从 IR 画布反查比例后再取 `maxChars`。
6. 新增 `rules/platforms.md`(平台表 + 安全区 + 优先级 + 坑位),登记进 `SKILL.md` 路由表与命令速查;新增硬规则 21(画幅/平台只查表)。

## 后果

- 加一个新平台 = 往 `platforms.json` 加一条;加一个新画幅 = 改 `rs_common.RATIOS` + `segmentation.MAX_CHARS/CPS_MAX` + `STYLES` 的 `3x4` 同位置,**其余模块自动跟上**;
- 平台差异第一次变成**可查询的数据**(Agent 不用背);测试里有"比例表一致性"用例,新增画幅漏改会立刻红;
- 平台与 `videoType` 正交:形态决定管线,平台决定发布规格。两者都进 brief;
- 代价:`platforms.json` 的 `fontSize`/`marginV` 与 `STYLES` 有潜在重复(约定以 `STYLES[style][ratio]` 为准,预设只作覆盖);
- 代价:3:4 的每卡字数(15)目前是**估计值**,需真实素材实拍观感定档;`maxChars` 是 data 字段,可改不用改码。
