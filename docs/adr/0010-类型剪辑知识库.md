# ADR-0010:类型剪辑知识库(rules/genres/,按视频类型单独成册)

状态:已采纳 ｜ 日期:2026-09-08

## 背景

用户要求"从网上查找权威资料,总结口播/动画教程/新闻采访/短剧/电影等类型的剪辑方法与固定规则,单独写成 Markdown 作为技能复用"。此前技能只有口播一种隐含节奏。

## 决策

1. `rules/genres/` 每类型一册:`口播知识.md`、`动画教程.md`、`新闻采访.md`、`短剧.md`、`影视解说.md`、`_通用规则.md`;
2. 每册固定结构:**节奏参数表**(可直接抄进 brief:镜头时长/字幕字数/视觉变化间隔/时长区间)→ **结构模板**(时间轴骨架)→ **字幕风格** → **音效音乐惯例** → **类型专属红线**(如新闻:不改语义不配乐;影视解说:版权四要素)→ **权威来源**(平台官方/行业标准优先,至少 2 个/类);
3. brief 增加 `类型` 字段,Agent 开工时**必读对应分册**并把参数写进 brief(节奏/字幕/动画密度默认值全部来自分册);
4. 参数可信度分级标注:平台官方/行业标准 > 权威机构 > 从业者经验(标"经验值")。

## 后果

- 技能从"只会口播"变成六类各有章法;新类型增量加册即可;
- 分册参数与 brief/渲染默认值可能漂移——SKILL 规定 brief 值优先,分册只在 brief 缺省时兜底;
- 知识有时效(平台规则会改),分册头部带"调研日期"。
