# ADR-0027:纯动画 IR 组装器(rs_ir build --from-cards)

状态:已采纳 ｜ 日期:2026-09-14(v0.12,安信德 GEO 纯动画工程实测)

## 背景

`pure-animation` 类型(16:9 / 19 张场景卡 / 158.93s 成片)在 CutFlow 里**没有 IR 组装入口**:`rs_ir.py` 只有 `build --from-cutlist`(choices = validate / build),而纯动画工程没有 CutList——主轨不是"源素材的 keep 区间",是"场景卡按旁白时间轴串联"。结果安信德工程自写了三个一次性脚本:`_gen_cards.py`(卡生成)、`_build_ir.py`(锚点分组+停顿切卡+冻结帧补长+BGM 裁齐)、`_smooth_wordline.py`(标点零宽+重叠钳制),并由此产生一串 bug:

- 锚点扫描 `if gi == g: break` 写法使锚点永不前进(g 从 gi 起步第一轮恒真)——"锚点扫描三连"的真凶;
- 「安信德GEO优化系统」被「交给安信德GEO优化系统」的后缀重复触发(锚点未消费命中串);
- `-t` 放输出侧把 tpad 冻结帧整段截掉(丢 20.4s);
- `_smooth_wordline.py` 把标点设成零宽(endMs=startMs)违反 rs_verify 单调门禁(147 个字 endMs≤startMs 硬失败);
- 手改 IR 产物被生成器覆盖。

"每个纯动画工程重写一遍易错脚本"不可接受,上游化。

## 决策

**`rs_ir.py build --from-cards <manifest.json> --anchors <cards.json> --wordline <wl.json> [--voice …] [--bgm …]`**(Q2 已拍板:挂在 rs_ir 名下而非独立脚本——IR 生成只有一处出口,`_manual_edits` 护栏与 validate 天然复用)。

输入:artboard manifest(卡清单,路径口径与 `rs_artboard --apply` 一致:工程根相对、归一化绝对路径匹配)+ wordline(时间唯一来源)+ 锚点表 `[{"card","match"}]`(match 支持 `|` 多候选)。

四条内置逻辑(全部来自实测):

1. **卡片↔旁白分组 = 字符级锚点扫描**(`assign_card_groups`):命中关键词即切组;**命中后消费 len(k) 个内容字**(防后缀重复触发);标点继承当前组;同卡相邻组合并(c16 双锚点);组号只进不退,循环用 hit 标志(代码注释明写禁 `if gi == g: break`);锚点**未命中显式报错**(空组不静默);同名组不相邻报错。锚词优先取句首词(句中锚让上一张卡拖尾)。
2. **组间边界 = 语音停顿中点** `((前组末字end + 后组首字start) // 2)`;卡比旁白短 → `clip.freezeMs`(渲染端 `-t` 只读到冻结起点——**输入侧**,B8——其后 tpad 克隆尾帧;冻结预留 950ms,在出场动画开始前定格)。`CACHE_VER` v4→v5(freezeMs 入 seg 缓存键)。
3. **生成式产物不得手改**:`--from-cards` 走与 `--from-cutlist` 相同的 `IR_MANUAL_EDITS` + `--force` 护栏。
4. **subtitle.ass 必须写全**(B4:只写 source = 静默不烧字幕);BGM 不预裁(step_mix 的 atrim + stream_loop 自动裁齐循环,ducking 修复后可默认开)。

## 影响

- 纯动画工程一条命令出 IR:3 卡最小工程已验证(锚点分组 → validate 全绿 → rs_render 出片);断句/卡数与人工核对一致;
- 副产:wordline 平滑上游化为 `rs_align smooth`(B7),纯动画/配音工程不再需要 `_smooth_wordline.py`;
- 渲染端新增 clip 字段 `freezeMs`(契约:源正常播放到该时刻,其后冻结到 durationMs),schema 后续随 v0.12 补(现 validate 不强制);
- CACHE_VER +1:旧 seg 缓存全部失效重渲一次(预期行为,CHANGELOG 已喊)。

## 回滚

`--from-cards` 为新增子命令,不触碰 `--from-cutlist` 路径;freezeMs 不写即走原渲染行为;CACHE_VER 回退 v4 即弃用冻结缓存(但 freezeMs 渲染语义仍在,回退仅影响缓存命中)。
