# ADR-0005:趣味素材(音效/贴图/花字)走"本地资产优先",不依赖剪映云端素材

状态:已采纳 ｜ 日期:2026-09-07

## 背景

用户希望用剪映的音效/贴图/花字增加趣味度。实测调查(2026-09-07):剪映 5.9 **无内置音效/贴纸库**,音效/贴纸/花字全部云端按需下载;本机缓存仅有 303MB 视频特效包(无可读名称映射)与 2 个 UI 提示音;草稿反解可得 id 但本机历史草稿零云端素材;pyJianYingDraft 的 StickerSegment/TextEffect 需要 resource_id,无离线来源。

## 备选

A. 引导用户在剪映 GUI 挑素材 → 保存草稿 → 反解 id 建库(jianying-editor-skill 路线):可行但依赖"用户先用过",AI 全自动流程断链;
B. 本地资产:CC0 音效包(Kenney 等)+ 安装目录自带中文风格字体(后现代体/悠然体/新青年体)做"花字感" + artboard 生成 PNG 贴图走图片轨;
C. 解析 Cache\effect 的 203 个 id 盲用:无名无类别,多数为人脸特效,放弃。

## 决策

**B 为正道**:assets/sfx/ 收录 CC0 音效(whoosh/pop/ding/riser 各若干,记 CREDITS);"花字"= ASS/草稿文本用本地风格字体+描边+底衬+text_intro 免费动画 id(vendored metadata 内置);贴图 = artboard 产透明 PNG 进 overlay 轨。剪映云端素材列为"GUI 可选增强"(路线 A 留给用户手动),不进自动管线。

## 后果

- 全自动、离线可复现、版权干净(CC0 + 自产);
- 失去剪映云端曲库/贴纸的丰富度——换来确定性;音效包体积小(数十 KB/个)可入库;
- 花字感与真·剪映花字有视觉差距,记录于 BACKLOG(用户 GUI 挑选后可回填 id)。
