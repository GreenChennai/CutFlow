# ADR-0003:绿幕合成管线 = 先裁非绿幕区,再抠像,再叠虚拟背景

状态:已采纳 ｜ 日期:2026-09-07

## 背景

v0.1.0 验收发现:素材顶部约 15% 是白墙而非绿幕,chromakey 后白墙原样留在画面上;且整条视频直接用绿幕原片,没有合成任何背景,"结果未达预期"。

## 备选与取舍

- **背景去除模型(RVM/rembg human matting)**:质量上限高,但逐帧推理慢(167s 视频),rembg 对视频接缝闪烁风险大;
- **顶部蒙版(alpha 置零)**:不破坏构图,但需要 alpha 乘法链(geq/alphamerge),慢且与 chromakey 的 alpha 相互覆盖;
- **先几何裁除非绿幕区(cropTop),再 chromakey**:一次线性裁剪,零额外算力,边界干净。

## 决策

管线固定三步:**crop(裁掉顶部非绿幕带,IR 新增 `cropTopPct`)→ chromakey+despill → 叠加 artboard 虚拟背景**(背景为 IR 主轨,抠像人像为 V2 全幅 overlay)。裁切比例由 Agent 抽帧目测确定,边界以人物头发不触顶为准。

## 后果

- 构图略放大(裁掉 15% 后人物占比升高)——对虚拟背景场景反而更合适;
- 若未来素材的头部越过绿幕上界,crop 方案失效,届时再引入 matting 模型(记入 BACKLOG);
- 虚拟背景必须是 artboard 产物(版权干净、风格统一),不做网图直用。
