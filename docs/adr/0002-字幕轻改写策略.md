# ADR-0002:ASR 字幕文本采用"轻改写"策略(音频不动)

状态:已采纳 ｜ 日期:2026-09-07

## 背景

口播原声与字幕同源(ASR)。把字幕改写成书面语有两种深度:①只动标点/删口水词/断句(音频可对照,零语义风险);②语义级改写压缩(字幕与音频脱节,观众对照时违和,且无人审有歧义风险)。平台调研结论:口语书面化属"剪辑优化技巧",主流流程 = 转写 → 删口水词 → 语义断句 → 校对。

## 决策

**轻改写**(①),规则可枚举、可单测:
1. 删句首/句尾 filler:嗯/呃/啊/嘛/呢(语气词,音频里有但字幕不写);
2. 标点规范化(ADR-0001):句号删除、逗号在断行点转空格、`……`→`…`、禁 `!?` 连用;
3. 按标点/评分算法做**语义断句**,单卡 ≤16 字(9:16)/≤22 字(16:9);
4. 时间轴:ASR 句级时间戳 + 按字符数比例插值到卡级。
明确不做:语义改写、信息删减、同义替换。这些留给 Agent 校对环节(human-in-loop 可选)。

## 后果

- 音画对照安全,规则可测试(pytest);
- 口语冗余仍在音频里,字幕只能"视觉减负"不能缩短时长;要缩短时长须配合剪辑(跳剪),另立迭代。
