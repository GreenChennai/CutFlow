# ADR-0011:Wordline 字级对齐时间轴作为时间的唯一真相源

状态:已采纳 ｜ 日期:2026-09-10

## 背景

用户反馈「字幕/声音/画面三者很难对上,通常是字幕声音对上了画面对不上,声音画面对上了字幕没对上,如果 AI 剪了之后还需要人工手动调节,那么整个视频就比人工一个个剪辑要慢得多得多」。

根因不是精度不够,而是**时间源不止一个**:

| 元素 | 旧时间来源 | 误差 |
|---|---|---|
| 画面 | Agent 手写 IR `sourceInMs` | 无校验 |
| 字幕(口播) | ASR **句级**时间戳 + **按字符数比例插值** | ±300–800ms |
| 字幕(TTS) | 各句 wav 时长**累加** | 累加漂移,句内无位置 |

两个放大器:① `sense.md` 规定「校对只改文本不动时间戳」,删字后字符数变了却仍按新字数摊到旧时间戳;② 一旦粗剪,时间轴整体重映射,三者各自重算 → 必然此消彼长。

**只要存在多于一个时间源,「对上」就只能靠巧合。**

## 决策

1. 新增 `05_ir/wordline.json`,全片**每一个字**一条记录,含**双坐标**:`startMs/endMs`(成片域)与 `srcStartMs/srcEndMs`(源素材域);
2. **`wordline.json` 是时间的唯一真相源**;字幕卡、动画入点、音效入点、Logo/章节锚点全部从它派生;
3. 新增 `rs_align.py` 导出**唯一允许的时间换算函数** `map_src_to_final(t_src, segments)`,由 CutList 的 keep 区间生成分段线性映射;落在被删区间的时刻**吸附**到下一个 keep 起点,不插值穿透,并保证单调不减;
4. **废除「按字符数比例插值」**——`rs_subtitle.py` 不再提供该路径;
5. 字幕卡时间 = 首字 `startMs` − 20ms 与末字 `endMs` + 20ms(首尾标点不计入时间跨度);
6. 优先取 **FunASR Paraformer 原生字符级 `timestamp`**(一次调用即得);取不到时降级为句级均分并在 `data.degraded` 与报告中**显式标注**,不静默降级;
7. 修订 `sense.md`:「只改文本不动时间戳」→「改文本后按**字级锚点重聚合**」(未改动片段沿用原字时间戳,新增字取相邻字区间均分且区间 ≤3 字,删除字把时间并给相邻字);
8. 新增 `rs_sync.py` 做机器断言:字幕↔Wordline 偏移中位数 ≤40ms、95 分位 ≤80ms;并给出可一键平移的系统偏差值。

## 后果

- 字幕 onset 误差从 ±300–800ms 收敛到 ≤±80ms(合成素材实测中位数 0ms、95 分位 3ms);
- 粗剪、调序、换 TTS 后,**所有下游时间自动正确**——不再需要人工对轴;
- 新增两类失败模式需监控:ASR 服务未透传字级字段(降级)、`fa-zh` 强制对齐的系统性偏移(见 ADR-0012 关联风险);
- 上游联动:建议 MomentShift `asr_server.py` 增补 `char_timestamps=1`(与 BACKLOG 已有的上游 PR 同类动作)。
