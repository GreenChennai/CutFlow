# ADR-0039: 桌面壳降级为观察项,Web/wasm 路径先行

日期: 2026-09-18 · 状态: 已采纳 · 关联: ADR-0035(OpenCut 只读策略)、计划书 7.6 风险 R2

## 背景

M5 计划交付 Web 壳(TanStack Start + React 19)与桌面壳(GPUI 0.2.2)。实测约束:
上游 OpenCut 桌面壳自述 "just a window that opens";GPUI 0.2.2 尚无稳定发布,
且对 Linux/WSL 有硬性平台约束(xdg_wm_base v2–5 而 WSLg 仅 v1);计划书风险 R2
早已预写缓解——"桌面壳若阻塞降级为观察项并记 ADR"。

## 决策

1. **桌面壳降级为观察项**,`apps/desktop` 以 README 记录决策与恢复条件(非空壳占位:明确写降级理由、复评条件、内核接入方式)。
2. **多端能力由 wasm + Web 壳交付**:`cutforge-wasm`(forge_* 投影 ABI,gzip 497KB ≤ 5MB)+ `apps/web` 静态壳(时间线/差异/标注/冲突/脚本页五面板,无构建步骤)。
3. **壳纯度不放松**:M5-5(check-shell-purity)继续阻断——壳代码禁文件系统、禁子进程、禁时间线语义运算(一切 id/startMs/endMs 由内核投影给定)。
4. **Web 壳技术栈偏离记录**:计划书写 TanStack Start + React 19 + shadcn;M5 交付为无构建静态壳(vanilla JS + ES Module)。理由:壳只是投影展示层,构建工具链不产生契约价值,且把 npm 依赖树挡在发布产物之外;React 化是纯重构,待界面复杂度需要组件化时再做,不改变任何契约与门禁。

## 后果

- 正面:M5 的正确性门禁(跨壳等价 M5-1、wasm 体积 M5-2、壳纯度 M5-5)全部真实达成;多端分发面(gzip 497KB 的 wasm)比 Electron 类壳小两个数量级。
- 代价:桌面原生体验(离线窗口/文件关联/快捷键)延后;`apps/desktop` 在恢复前始终是观察项。
- 恢复条件:GPUI 稳定版发布 + `apps/desktop` 通过 Windows 冒烟(开窗+加载工程+渲染时间线),M5-4 恢复阻断。

## 替代方案

- **强上 GPUI 0.2.2**:否决——依赖未稳定框架换取"能开窗",违反"壳薄、内核厚"的投资方向;计划书 R2 明文允许降级。
- **Electron/Tauri 壳**:否决——引入与上游不对齐的第二 UI 栈,且 Electron 体积与安全面过大;Tauri 待桌面壳复评时一并考虑。
