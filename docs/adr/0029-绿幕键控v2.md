# ADR-0029: 绿幕键控 v2 —— 亮度无关比值键控 + YUV 去混合

日期: 2026-09-15 · 状态: 已采纳 · 关联: ADR-0003(绿幕合成管线)、ADR-0022(边缘精修)

## 背景

v0.10-0.12 的键控链 `colorkey → despill → alpha 腐蚀/羽化` 存在三类根因缺陷:

| 缺陷 | 现象 | 根因 |
|---|---|---|
| **黑边** | 人物边缘暗色硬边 | `despill=green` 对边缘混合像素做 RGB 钳位(G 钳到 max(R,B)),半透明像素被压暗 |
| **暗场** | 暗角/投影下背景残留暗块 | colorkey 是 RGB 欧氏球,对亮度缩放不免疫:暗角绿幕离键色球心变远,键不掉 |
| **吃边** | 边缘过渡生硬、发丝丢失 | colorkey 对混合像素近二值处理,腐蚀链进一步吞掉半透明带(难例实测 eaten≈90%) |

## 决策

默认启用 v2 键控器(`chroma.keyMode="v2"`,可回退 `"legacy"`),分三级:

### 1. Alpha:亮度无关比值键控

```
ratio = G / max(R, 1)     (绿幕;蓝幕自动切 B/max(R,1))
alpha_raw = 255 * clip(keyTcut - ratio, 0, 1)      # 二值 matte
alpha = blur(alpha_raw, keyFeather) → tighten(0.25-0.75 重映射)
```

- RGB 由 limited-range YUV 现场还原(geq st/ld),全程单链无中间转换
- **亮度无关性**:屏幕绿 G/max(R,B)≈4.0,在暗角(vignette 0.45)、投影(0.6)、热斑下
  恒定不变(所有通道同乘亮度系数,比值消掉);人物任何颜色 <3.5
- 二值 matte 的半透明由 matte blur 空间平均给出(专业键控器的 matte blur 做法)
- tighten 曲线把过渡带按 0.25-0.75 收窄,轮廓回位、抑制光晕外扩

### 2. 色度:YUV 域 alpha 感知去混合(un-premultiply)

```
ae = max(alpha/255, keyAFloor)
Y'  = (Y-16  - (1-ae)*(Ys-16 )) / ae + 16
Cb' = (Cb-128- (1-ae)*(Cbs-128)) / ae + 128    (Cr 同理)
```

- limited-range YUV 对混色是线性的:像素 = alpha·前景 + (1-alpha)·屏幕 → 精确反解
- **这是黑边根治的关键**:R/B 通道(Y 平面)永不触碰;旧链 despill 在 RGB 域钳 G,
  边缘混合像素被压暗——新链没有任何压暗运算
- 单像素色度修正钳 ±40:抑制细发丝/4:2:0 色度块下 alpha 低估导致的去混过冲(紫边)

### 3. 溢色:分离门控软中和

```
Cb'' = Cb' + (128-Cb')·keyDespill·clip((122-Cb')/25, 0, 1)
Cr'' = Cr' + (128-Cr')·keyDespill·clip((115-Cr')/25, 0, 1)
```

- 只在色度仍偏"键色方向"时向中性收,强度随偏离量线性;
- R/B 通道不参与,黄/橙/肤色不受影响;残余绿边(spill)较 despill 硬钳降低 45%+

### 4. 第二判据:混合线距离(保护绿色前景)

绿色服饰(绿衣 G/B≈2.4)落在比值判据的歧义带。补充:

```
dline = |(128-Kcb)·(cr-Kcr) - (128-Kcr)·(cb-Kcb)| / |(128-Kcb, 128-Kcr)|
alpha_dist = 255·clip((dline-keyDistCut)·0.5, 0, 1)·clip((ratio-keyTcut)·3, 0, 1)
alpha = max(alpha_ratio, alpha_dist)
```

几何依据:背景任何混色(含 4:2:0 漂移)的色度都在"键色→中性灰"连线上
(dline 0-2),绿衣 dline≈11 明显偏离——干净分界。ratio 门控保证纯背景
(ratio 极高)不受影响。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `keyMode` | `v2` | `legacy` 回退 v0.10-0.12 链(colorkey+despill+腐蚀) |
| `keyTcut` | 2.2 | 比值阈值:低于判前景。键不掉背景→调大;吃前景→调小 |
| `keyFeather` | 1.2 | matte 模糊 sigma(空间 AA/半透明来源) |
| `keyAFloor` | 0.35 | 去混合 alpha 下限,低于它数值不稳 |
| `keyDespill` | 0.85 | 溢色中和强度 0-1 |
| `keyDistCut` | 3.0 | 混合线距离第二判据门槛(绿色服饰保护) |

`edgeShrink/edgeShrinkT/edgeFeather/killRects` 仅 legacy 模式生效。

## 验证(tests/test_v13.py + tests/rs_chroma_bench.py,1280x720,难例:暗角 45%/投影 60%/4:2:0)

| 指标(越低越好) | v0.10-0.12 | v2 | 变化 |
|---|---|---|---|
| alpha MAE(全图,0-255) | 22.6 | 12.5 | **-45%** |
| 黑边像素 fringe%(均匀光) | 4.9 | 0.0 | 清零 |
| 黑边像素 fringe%(投影+420) | 23.3 | 7.7 | -67% |
| 背景暗场 darkhole%(投影) | 0.09 | 0.0 | 清零 |
| 边缘误差 p95(均匀光) | 48.5 | 40.2 | -17% |
| 边缘误差 p95(投影+420) | 94.9 | 71.1 | -25% |
| 边缘保留率(1-eaten) | 6.8% | 57.4% | **8.4×** |

已知限制:
- 绿色/蓝色服饰与幕布同色系时仍有固有歧义(靠 keyDistCut 缓解,极端场景建议换幕布色)
- 极暗幕布(亮度 <40/255)色度信噪比不足,任何色度键控都会退化
- 性能约为旧链 3-5 倍(双 geq),1080p 实时性无影响(渲染为离线管线)

## 影响

- `rs_render.step_segment/step_compose` 默认走 v2 链;`CACHE_VER v5→v6`(旧 segcache 全失效)
- schema 补 `keyMode/keyTcut/keyFeather/keyAFloor/keyDespill/keyDistCut`
- `rs_chroma_bench.py` 正式化:合成难例(暗角/投影/4:2:0)+ 像素级指标 + 参数网格搜索
