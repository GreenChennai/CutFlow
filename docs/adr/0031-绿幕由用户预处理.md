# ADR-0031: 抠像与背景合成移交用户 + S0 幕布检测门禁

日期: 2026-09-16 · 状态: 已采纳 · 关联: ADR-0003(绿幕合成管线,已作废)、ADR-0022(边缘精修,已作废)、ADR-0029(绿幕键控 v2,已作废)

## 背景

v0.6–v0.13 CutFlow 自带一族绿幕键控实现(基轨/叠加层的 `chroma` + `background`:
`colorkey`/`chromakey`、`despill`、alpha 腐蚀羽化、killRect、v0.13 的比值键控 v2)。
这条链路带来持续成本:

1. **算法天花板**:实拍绿幕的打光不均、投影、溢色、与幕布同色的服饰,本质是**拍摄与预处理
   问题**,算法只能补到有限程度(ADR-0029 已记录固有歧义与极暗幕布退化);
2. **维护面大**:键控参数(similarity/blend/keyTcut/... 十余个)、matte 探针、缓存语义、
   剪映降级标注,散落在 render/ir/schema/verify/jy/文档与测试中;
3. **职责错位**:抠像与背景合成是**素材预处理**环节,更适合在剪映/Pr/AE 里由用户按需完成
   (尤其需要精细控制或已有既定背景时),CutFlow 的价值在**剪辑**(粗剪/字幕/节奏/品牌)。

## 决策

1. **移除抠像与背景合成**:`chroma`/`background` 字段、键控实现、matte 探针、相关 schema/
   校验/文档/测试全部删除;IR 若仍带这两个字段,`rs_ir validate` 明确报错并给出迁移指引。
2. **用户预抠像**:`talking-head` 系素材须由用户先抠像并合成好背景,再把处理完的成片交给管线剪辑。
3. **S0 幕布检测门禁**(`rs_greenscreen.py`):
   - 抽取若干帧(缩放为 64px 宽 RGB),统计幕色像素占比:
     边框环(外 20%)占比 ≥0.45、全帧占比 ≥0.18、幕色亮度离散度 cv ≤0.40(区分草地/树叶等自然绿);
   - 三条件同时满足才判"绿幕/蓝幕"(误报可被用户放行,**漏报才是事故**);
   - `rs_ingest scan` 命中且无放行 → **阻断 S0**(`GREEN_SCREEN_INPUT`),写
     `01_materials/GREENSCREEN.md` 处理指引;
   - `rs_verify` L0 新增「素材无未处理幕布」判据,交付前二次把关。
4. **误判放行**:用户说明后 `rs_ingest.py green-ok <工程> --reason "…"` 记录到
   `00_brief/greenscreen-override.txt`(也接受 brief.md 的「绿幕检测:误判…」行),
   留痕可审计;manifest 标 `overridden`。

## 判据为何是"边框占比 + 全帧占比 + 均匀度"

- 幕布是**背景**:通常铺满画面且边框几乎全为幕色 → 边框占比是最强信号;
- 全帧占比设较低阈值(0.18),容纳幕前有较大人体的情况;
- 纯绿色自然场景(草地/树叶)不均匀 → 亮度离散度 cv 越限即否,降低误报。

## 影响

- `rs_render`:删除 `sample_chroma/chroma_hex/_chroma_key_v2_chain/_chroma_fg_chain/
  _crop_pct_chain/parse_matte_log/matte_fg_ratio/matte_probe_args`、`CHROMA_DEFAULTS`、
  `BG_TYPES`、基轨背景合成与 matte 探针;`CACHE_VER v6→v7`(旧 segcache 全失效)。
- `rs_ir`:删 `_validate_chroma_bg`,加 `_validate_removed_fields`(旧字段显式报错);
  `_manual_edits` 仍把 `chroma/background` 视为手注痕迹(兼容旧工程,防静默覆盖)。
- `rs_ingest`:新增 `rs_greenscreen` 检测与 `green-ok` 子命令;manifest 增 `greenScreen`/
  `greenOverride`;`MANIFEST.md` 增"幕布"列。
- `rs_verify`:新增 `check_greenscreen` L0 判据。
- `rs_jy_draft`/`rs_run`/schema/规则文档:删除绿幕相关警告与说明。
- 测试:`tests/test_v10.py` 增「抠像 helper 全部移除」断言;新增 `tests/test_v14.py`
  (帧级判据 / 放行留痕 / S0 门禁 / L0 闸 / 真实视频抽帧);删除 `chroma_pixels.py`、
  `rs_chroma_bench.py` 及旧键控测试。

## 备选方案

- **保留键控但默认关闭**:仍要维护整条链与测试,且默认关闭等于仍提供一条会被误用的路径 —— 否。
- **只检测不阻断(仅告警)**:用户容易忽略告警,绿幕成片会流入交付 —— 否(检测到的价值在于拦)。
