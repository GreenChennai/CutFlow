# ADR-0009:视频卡安全区规范与纯动画视频的场景全覆盖

状态:已采纳 ｜ 日期:2026-09-08

## 背景

v0.2 验收发现穿插动画卡的排版问题:①上下/左右安全距离不足,元素叠压;②卡片文字与字幕位置粘合;③纯动画视频大部分时间是空白静态背景,只有节拍点才有卡片,"动画演绎"名不副实。另外口播类如用户要求也应增密动画。

## 决策

1. **视频卡安全区**(artboard 卡模板硬约束):顶部 12%、底部 30%(字幕区,大留白)、左右 8%;核心内容置于中央带(垂直 15%–68%);卡片内文字量 ≤3 组元素。设计稿导出后须通过"字幕区自检":把 9:16 字幕带(mask)叠上去目测无叠压。
2. **场景覆盖**:纯动画视频的底不应是静态 PNG——背景升级为 artboard 6s **无缝循环动画 MP4**(仅 transform/opacity),IR clip 支持 `loop: true`(-stream_loop);场景节奏 = 背景 2–3s 微动 + 每个语义节拍一张全屏卡,保证"整个视频都是动画/静态帧节奏"而非空白。
3. **口播动画密度**:brief 新增 `穿插动画: 无/少/多`(默认 少=4 卡;多=每 30s 一张 + 关键词花字)。
4. 卡片时段字幕避让:卡片显示期间 ASS 字幕自动下沉至底部安全带并降透明度(写入 rs_render 字幕步,先记录为约定,实现随迭代)。

## 后果

- 卡片信息不与字幕打架,观感完整;纯动画视频不再"大部分空白";
- 循环背景增加渲染输入数量(25 段 concat),渲染时间略增;
- 安全区数值来自 ADR-0004 调研(顶部状态栏/底部 UI 区)与字幕带实测,非拍脑袋。
