# ADR-0030: 字幕-人声对齐校准(能量包络 FMSmartSnap)

日期: 2026-09-15 · 状态: 已采纳 · 关联: ADR-0011(字级对齐 wordline)、ADR-0015(自带 ASR)

## 背景

wordline 的字级时间戳来自 FunASR Paraformer,存在两类偏差:

1. **系统性偏移**(引擎延迟/时间基差异):整轴提前或滞后 100-200ms,
   直接决定字幕观感("字幕抢拍"/"字幕拖拍");
2. **局部误差**(快语速段/静音边界):VAD 切片边界的起点吸附误差。

门禁(`rs_sync`)只能**检测**偏差,没有**修正**手段;校对回灌(retext)只管文本不管时间。

## 决策

`rs_align.py` 新增 `calibrate` 子命令(S1 的 post 步骤,自动执行):

### 原理

1. 提取音频 RMS 能量包络(10ms 窗,mono 16kHz,纯 stdlib,无 numpy 依赖);
2. 自适应活跃掩码:`env > max(噪声底×3, 峰值×8%)`(噪声底=20 分位);
3. 每句在 ±window(默认 250ms)内用**连续活跃段**(50ms sustained)定位能量起点;
4. 起点 vs 时间戳的偏差 ≥ minShift(默认 20ms)才修正——抗噪声抖动;
5. 偏移写回 chars(域内同步 src* 字段,保持 remap 锚一致);守单调性;
6. 重算 gaps,报告前后偏差(median/p95)与逐句修正量。

### 为什么能量起点而非互相关

- 互相关对合成/音乐背景音敏感;语音的能量起点(onset)是物理事件,鲁棒且可解释;
- 字级时间戳已经"形状正确",只需对齐整轴/句级偏移——onset 定位即可,无需波形配准;
- 纯 stdlib 实现(O(n) 单遍),8s 音频 <50ms,不构成管线瓶颈。

### 门禁协同

- `rs_sync` 门禁不变(median ≤40ms / p95 ≤80ms);
- calibrate 在门禁**之前**运行,门禁因此更常直接通过,减少人工介入;
- `wordline.calibrated=true` 与 `calibration` 报告落盘,审计可见。

## 验证

- 合成偏移素材(4 句 440Hz 语音包络,整体 +150ms):校准后中位偏差 140ms→0ms
  (改善 100%,门禁要求 ≥30%);
- 无偏移素材:0 句被修正(抖动保护生效);
- 静音素材:显式降级说明("无可检测语音能量"),不崩溃;
- 损坏文件:`PCM_EXTRACT_FAIL` 明确报错。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--calib-window` | 250 | 能量起点搜索窗口 ms(±) |
| `--calib-min-shift` | 20 | 小于此偏移不修正 ms |

## 影响

- `rs_run.py` S1 注册表加 `post` 步骤;`build_cmd_from_argv` 泛化出 post 执行;
- 下游(rs_subtitle/rs_cut/rs_ir)零改动——它们读的是校准后的 wordline;
- TTS 路径(纯文案)不走 calibrate(没有原始人声音轨可测),保持原状。
