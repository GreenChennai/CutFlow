# ADR-0004:口播穿插动画采用"知识/数据/对比/章节"四类 artboard 卡 + 2–3 秒视觉节拍

状态:已采纳 ｜ 日期:2026-09-07

## 背景

用户指出口播成片"通篇口播,过于无趣生硬",要求按"知识/数据/新闻类"补充动画穿插,并以权威内容巩固专业性。

## 权威依据(调研 2026-09-07)

- **视觉节拍**:短视频剪辑圈广泛实践的 "2-Second Rule"——画面每 2–3 秒需要一个可感知变化(切换/动画/弹字均算);"3-Second Rule"——前 3 秒决定留存,弱开场约 40% 观众流失(Reddit r/SmallYTChannel、opus.pro、Animoto 基准 3 秒留存 ≥70%);
- **动效原则**:Disney 十二原则之 slow-in/slow-out(easing)与 Material Design "动效服务于注意力引导"——变化要有缓动、勿过度。

## 决策

1. 卡片四类型:**知识卡**(定义/要点)、**数据卡**(数字强调)、**对比卡**(A vs B)、**章节卡**(序号标题);artboard 生成 MP4(25fps,3–8s,GSAP transform/opacity,入出有 easing);
2. 插入节拍:全片无变化的空窗 ≤3 秒;在口播的"论点切换处"插卡,每卡 5–8 秒,出卡后回落人像;
3. 卡片文字必须与该时刻字幕/台词语义一致(不引入台词外的新信息,防"看字听音两套话");
4. artboard 动画卡遵守其动图规范(仅 transform/opacity,终态须为合格静帧)。

## 后果

- 口播不再"一张脸到底";卡片素材可跨视频复用(风格 token 驱动);
- 卡片时间点依赖转写时间轴,ASR 句级时间戳的误差直接变成插卡误差——插卡时刻取句首时间戳并前后留 300ms 缓冲;
- 全屏卡会盖住人像,出现频率约束在每 30–40 秒一张,避免"动画视频化"。
