# ADR-0043: 片尾保底:口播结尾保留 0.5–0.8s 自然底噪

日期: 2026-09-20 · 状态: 已采纳(2026-09-20 迭代落地) · 关联: ADR-0042(wordline 时长以 ffprobe 实测为准)、ADR-0012(粗剪阶段与 cutlist 决策表)

## 背景

真实事故:cutlist 的 keep 末段终点若钉在末字 `endMs`,即使时长记录正确,也会把语音结束后自然衰减的尾音与室内底噪一并切掉——听感是"说完一瞬间硬停",交付观感差。语音的"说完"与"声音消失"之间有数百毫秒的自然间隔,机械贴字尾切刀必然抹掉它。

## 决策

1. **keep 末段终点 = max(末字 `endMs` + 尾余量, 实测媒体时长)**;口播的尾余量取 0.5–0.8s,默认 650ms。
2. 尾余量是粗剪语义的一部分,随 cutlist 留痕(`tailReserveMs`),下游体检与对账可据此核查。
3. 与 ADR-0042 联动:终点计算中的"实测媒体时长"以 ffprobe 为准,禁止用上游记录值兜底——否则记录值偏短时保底失效。

## 取舍

- 付出:成片比"贴字尾硬切"长 0.5–0.8s。
- 换来:结尾保留自然衰减与底噪,"不割裂"的听觉完整度;这是内容类成片的基本观感底线,半秒的时长代价可接受。

## 被否决的替代

- **贴字尾硬切**:否决——"说完瞬间硬停"的交付观感差,用户侧必被感知。
- **尾余量写死一个全局常量、不可调**:否决——不同题材对结尾余韵的容忍不同,必须保留显式参数且默认值落在建议区间内。

## 后果

- 保底生效后,片尾实际留白由 max(尾余量, 剩余媒体) 决定;时长账需随之下沉到成片空间(`finalDurationMs`),对账口径以成片实测为准。
- 改默认尾余量属于行为变更:同步改手册、能力目录与测试基线三处,缺一即漂移。
