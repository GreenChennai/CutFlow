# ADR-0001:字幕文本规范采用 Netflix 简体中文 Timed Text 规范 + 抖音低质判定标准

状态:已采纳 ｜ 日期:2026-09-07

## 背景

v0.1.0 验收发现字幕"基本全搬 ASR 原文、标点未优化、观感死板"。用户要求"从网络查找权威资料优化字幕"。候选规范:Netflix 简体中文 Timed Text Style Guide(影视级、公开、可执行)、YouTube 字幕指南(英文为主)、抖音平台规则(只定"无错别字/时间轴同步"红线,无排版细则)、中文文案排版指北(通用排版,非字幕)。

## 决策

以 **Netflix 简体中文规范**为排版基准(16 字/行、≤2 行、句号/逗号不入屏、问号感叹号保留、顿号不入行尾、U+2026 省略号、禁 `!?` 连用、全角引号、一至十汉字),以**抖音低质判定标准**(无错别字、时间轴同步)与**星图字幕红线**(无促销/导流字样)为平台合规底线。合并为 rules/subtitles.md 的"字幕规范"节。

## 后果

- 字幕观感有公开权威背书,规则可枚举、可测试;
- Netflix 规范面向影视对白,短视频的"口语书面化"它不管——轻改写策略另立 ADR-0002;
- 抖音规范会更新,规则表需随迭代维护。
