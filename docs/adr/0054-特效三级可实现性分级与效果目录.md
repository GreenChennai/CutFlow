# ADR-0054: 特效的三级可实现性分级与「效果目录」

日期: 2026-09-26 - 状态: 已采纳(v0.20 已落地) - 来源: 《CutFlow-迭代计划-v2-20260925》主册 §3(转写自桌面蓝本,以蓝本为权威)

**状态**：已采纳(v0.20 已落地) · **关联**：v1 ADR-0047（能力注册表）、ADR-0051（风格包）、`docs/ITERATION-GUIDE-v0.11.md` §10（出处分级）

#### 背景

用户提供了 **1000+ 条剪映效果名**（入场 / 出场 / 组合 / 转场 四大类，各含基础/运镜/特效/MG/幻灯片/遮罩/综艺/组合子类）。这批名字是**剪映的 GPU 着色器效果**，而 CutFlow 的渲染 Golden 基准是 **FFmpeg** —— 绝大多数**原生做不到**。

用户授权：**「部分效果不常用 / 可能根本用不上的部分不用做；同时补充缺失的但是常用的」**。

#### 决策

1. **三级可实现性分级**（每条效果必须归入且只归入一级）：

| 级 | 名称 | 判定 | 落地方式 |
|---|---|---|---|
| **T1** | **原生可做** | FFmpeg 现有滤镜/滤镜链可表达 | `xfade` 转场、`fade`(白/黑/灰)、`zoompan`、`rotate`、`gblur`、`perspective`、`rgbashift`、`chromashift`、`pixelize`、`xstack`、`freezeframes`、`tpad`、`overlay`+表达式、`setpts`/`atempo` 等 |
| **T2** | **GLSL 可做** | 需着色器，但已有开源实现 | `gl-transitions`（MIT，约 100 条，**实测约 60 条开箱可用**）；渲染路径见第 2 条 |
| **T3** | **预渲染或独占** | 需 artboard 预渲染，或**仅剪映可实现** | 花字级特效、玫瑰/枫叶/水蛋等**图形遮罩类**、`iPhone状态栏`/`News开场`等**品牌模板类**——走 artboard 模式 S 预渲染成 MP4 片段，或如实标「仅剪映」 |

2. **T2 的渲染路径 —— ✅ 已定案走 B3**（用户 2026-09-26 确认）：

| 项 | 内容 |
|---|---|
| **决策** | **B3：独立 GL 渲染器预渲染**。Python `moderngl` + `gl-transitions` GLSL → 输出中间 MP4 → 交给现有 concat 链 |
| **理由** | **不动 `fetch_ffmpeg.py` 的下载链** —— 三条路径里唯一不碰 ffmpeg 供应链的 |
| **代价** | 一次性写一个 GL 渲染器（`rs_fx/t2_glsl.py`）；新重依赖 `moderngl` 走 v1 ADR-0049 懒加载三态 |
| **落地要点** | ①**只渲转场重叠区**，不整片渲；②与现有 `joinCrossfadeMs` 尾帧扩展模型**共享零漂移约束**；③缺失依赖 → 降级最接近的 T1 + `fxDegraded` 留痕；④`gl-transitions` 逐条验证（实测约 60% 开箱可用） |

**已否决的替代（记录理由，防止日后重开）**：B1 = `libplacebo` 自定义 shader（需换 ffmpeg 构建，供应链风险高）；B2 = `ffmpeg-gl-transition`（必须自编译 ffmpeg，与「自带 ffmpeg 一键部署」冲突）。

> **诚实的提醒**：B3 仍要引入**新的重依赖**，必须走 v1 ADR-0049 的懒加载三态（缺失即降级为「最接近的 T1 效果」并留痕）。

3. **「效果目录」是全量登记，不是全量实现**：

- 你给的清单**逐条规范化**（去重 / 纠 OCR 错字 / 统一命名 / 合并同义）后**全部登记**进 `templates/effects/catalog.json`；
- 每条带字段：`id / 中文名 / 类别(入场/出场/组合/转场) / 子类 / 分级(T1|T2|T3) / 可执行(fxId 或 null) / 常用度(高|中|低) / 状态`；
- **`status` 为三态**：`可执行` / `登记待实现` / `不实现`（**`待确认` 已取消**，见第 4 条）。

4. **「不实现」的判定标准**（用户授权「用不上的不用做」）：

| 判据 | 处置 |
|---|---|
| 图形遮罩类且与内容强绑定（玫瑰/枫叶/水蛋/樱花/爱心系列） | **不实现**（`T3`，建议走 artboard 一次性定制） |
| 品牌/界面模板类（`iPhone状态栏`/`NEWS开场`/`报纸拼贴`/`手机开屏`） | **不实现**（artboard 定制或剪映） |
| 名字含明显 OCR 噪声且无法确认语义（`川`/`克虹`/`因弧`/`官格`/`美镜`/`篦浪`…） | **✅ 已决策：直接删掉**（用户 2026-09-26）→ `status: 不实现` + `why: "语义不明，用户确认删除"`；`search` 返回 **`EFFECT_REMOVED`**（明确结论，**不再走「待确认」流程**）；条目保留在 `sources/` 原始清单中并标注，以便日后查到它是「有意删除」 |
| 与已有条目视觉等价（`渐隐` vs `渐隐消散`、`闪白` 出现多次） | **合并为一条**，保留别名 |
| 其余 | 按 T1/T2 实现或登记待实现 |

5. **补充清单里缺失但常用的效果 —— ✅ 已扩为「标准 NLE 通用效果词典」共 62 条**（用户 2026-09-26 要求「常用缺失必须补齐」）：

- **判断依据**：你给的剪映清单**装饰性/视觉化效果极丰富**，但缺的恰是**专业剪辑语言的标准语汇**（Premiere / Resolve / Final Cut / AE 的标配）——剪映偏向"看起来热闹"，这批是"**看起来专业**"；
- **转场 24 条**：`tr.fade.black`（Dip to Black）、`tr.fade.white`、`tr.dissolve.cross`、`tr.blur.dissolve`、`tr.wipe.linear`（任意角度）、`tr.iris.circle`、`tr.push.dir`、`tr.roll.dir`、`tr.whip.pan`、`tr.invisible.cut`、`tr.match.cut`、`tr.lcut`、`tr.jcut`、`tr.audio.crossfade`、`tr.speed.ramp`、`tr.punch.zoom`、`tr.flash.zoom`、`tr.hold.frame`、`tr.light.leak`、`tr.film.burn`、`tr.glitch.slice`、`tr.gradient.wipe`、`tr.shape.wipe`、`tr.morph.cut`；
- **入场 26 条**：`in.fade.up/down/left/right`、`in.anchor.scale`、`in.scale.pop`、`in.blur.in`、`in.wipe.dir`、`in.clip.reveal`、`in.stagger`、`in.text.char/word/line`、`in.typewriter`、`in.count.up`、`in.progress.bar`、`in.ring.progress`、`in.glow`、`in.shadow.drop`、`in.skew`、`in.breathe`、`in.bounce.pop`、`in.lower.third`、`in.mask.reveal`、`in.stroke.draw`、`in.cursor.click`、`in.keystroke`；
- **出场 10 条**：`out.fade.*`、`out.scale.shrink`、`out.blur.out`、`out.wipe.dir`、`out.stagger`、`out.spin.fade`、`out.mask.close`、`out.collapse`、`out.letterbox`、`out.slide.off`；
- **组合 2 条补齐**：`fx.compare.slider`（对比滑块）、`fx.spotlight`（聚光灯跟随）；
- 完整表与配方见 **分册02 §6**。**这下可执行档从 ≈130 条升到 ≈192 条**（T1 ≈170 + T2 20–30）。

#### 取舍

- 付出：一次性的清单规范化工作量（1000+ 条）；`catalog.json` 需长期维护。
- 换来：**Agent 查一次目录就知道某效果能不能做、怎么做**；不虚报能力；用户清单不丢。

#### 被否决的替代

- **只做 40–60 条精选、其余不登记**：否决——用户已选「全量登记」；且登记成本低、可查性价值高。
- **全量实现（自研 GLSL 转场库）**：否决——图形类效果性价比极低，且会把工程量推到不可控。
- **把剪映效果名直接当 API 名暴露**：否决——剪映名含 OCR 噪声且会漂移，必须用自己的稳定 `fxId`。

#### 四问

| 问 | 答 |
|---|---|
| **旧工程怎么办** | 现有 5 种转场与 `motion` 枚举**保持不变**（作为 `fxId` 的既有值）；旧 IR 不需要迁移。 |
| **门禁怎么把守** | ①`tests/test_effects.py`：`catalog.json` 的 `分级` 与 `可执行` 字段自洽（`status: 可执行` 必须有 `fxId` 且该 `fxId` 真实存在于渲染端注册表）；②`status: 可执行` 的效果必须有测试或渲染冒烟；③**`status: 不实现` 必须给出非空 `why`**（含 §4 的「用户确认删除」类）；④**删除项可查**：§5 每个条目 `search` 返回 `EFFECT_REMOVED` + `why`，而非"待确认/未找到"；⑤`tests/test_effects_license.py`：`tier: T2` 的 `license` 非空；⑥`tests/test_fx_glsl.py`：B3 渲染器只渲重叠区、零漂移、缺失即降级留痕。 |
| **怎么验收（v2 增量）** | ①§6 的 **62 条标准 NLE 效果全部可用**（尤其 `tr.fade.black` / `tr.dissolve.cross` / `tr.lcut` / `tr.jcut` / `in.fade.up` / `in.stagger` / `fx.compare.slider`）；②可执行档从 ≈130 升到 **≈192 条**；③T2 走 B3 且移除 `moderngl` 后能降级。 |
| **怎么验收** | 从 `catalog.json` 随机抽 T1 效果 20 条，全部能渲染出片且视觉符合命名；T2 抽 5 条（若 T2 已落地）；`T3` 抽 5 条给出 artboard 预渲染样例或「仅剪映」说明。 |
| **怎么回滚** | `catalog.json` 为纯数据；回滚即还原文件。渲染端注册表按 `fxId` 查表，未注册的 `fxId` 报错而非静默。 |
